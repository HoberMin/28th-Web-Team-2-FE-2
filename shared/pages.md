## 2026-08-13 v2 — 화면 코드 체계를 Figma에 맞춰 전면 교체

Figma `화면GUI(원본)`(file `d5j7K9BNpSXxVUu3fmZfY4` / node `364:6742`)을 MCP로 전수 조회한 결과,
**최상위 프레임 47개 = 화면 14종**이었고 이 문서의 화면 코드 체계와 광범위하게 어긋나 있었다.
직전 갱신(08-13 v1)이 "Figma를 정본으로 확정하고 갱신했다"고 적었지만 **실제로 맞춘 건 F04 제보 흐름뿐**이고,
나머지는 07-31~08-04 프로토타입 시기의 옛 번호를 그대로 두고 있었다. **Figma를 정본으로 두기로 하고
코드를 전부 교체한다** — 아래 §구 코드 대조표로 승계 관계를 남긴다.

파일 전체를 확인했다: `(공유) GUI` 페이지에 위 섹션 하나뿐이고, `🔒 브랜딩/와프 작업실` 페이지의
`2차 UT`·`화면GUI` 섹션은 구버전 사본이라 정본이 아니다.

## 코드 체계 규칙

- **Figma 프레임명이 진실 소스다.** 코드는 프레임명의 접두사를 그대로 쓴다.
- Figma에서 **한 번호가 여러 화면을 가리키는 경우**(F03) 문서에서만 `-N` 접미사로 분해한다.
  캔버스 배치 순서(위→아래)를 따랐다. **이 접미사는 문서 전용이고 Figma에는 없다** —
  Figma를 지목할 땐 항상 프레임명 전체를 쓴다.
- 화면 특정에는 **프레임명 전체**를 쓴다. 번호만으로는 유일하지 않다.
- 코드 라우트에는 F 번호를 박지 않고 서술형(`/report/*`)으로 둔다 — 화면 코드가 또 바뀌어도
  URL이 흔들리지 않게 하려는 것이고, 실제로 08-13에 두 번 바뀌었다.

화면별 기능 정의는 → `detail-features.md` / 46종 데이터 규격은 → `kamis-vegetable-data-spec.md`
