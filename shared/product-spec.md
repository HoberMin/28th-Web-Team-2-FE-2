# 제품 페이지 스펙 (단일 진실 소스)

> 정책·엔티티는 `domain.md`. 이 문서는 **페이지 단위**: 목적 / 역할 분기 / 보여질 데이터 / 화면 항목 / 상태 3종 / 렌더링·캐싱 전략 / 디자인 방향 / 분석 이벤트.
> wireframe-builder·flow-reviewer·frontend-dev가 참조.
> **⚠️ 스켈레톤 상태** — 서비스가 정의되면 페이지 인벤토리부터 채운다.

## 페이지 템플릿 (새 페이지 추가 시 이 형식으로)

```
# N. 페이지명 ✅/🔸

**목적**:
**역할 분기**:
**보여질 데이터**:
**화면 항목**:
**상태 3종**: 로딩= / 에러= / 빈=
**렌더링·캐싱**: RSC 정적/동적 여부, revalidate/tags, "use client" leaf 목록   ← 이 프로젝트 신설 항목
**디자인 방향**:
**분석 이벤트**:
```

화면 코드는 Figma `화면GUI(원본)` 프레임명에서 오고, 2026-08-13 v2에 전면 교체됐다
(구 F07→F03-2, F09→F03-3, F01-1→F02, 「찜」→F04). 여기에 페이지 스펙을 쓸 땐 위 템플릿의
제목에 **신 코드 + Figma 프레임명**을 같이 적는다. 예: `# F03-3 가게 상세 (F03_가게상세)`.
