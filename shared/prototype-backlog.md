## 남은 것

- [ ] 개인화 카드가 localStorage라 하이드레이션 후 떠서 홈 첫 화면이 덜컥거림
- [ ] 터치 타겟 44px 미달 — 홈 위치 라벨, 내 제보 더보기 버튼, 단골 해제 버튼, 내 정보 동네 활성화 버튼
- [ ] 카카오 근처 가게 검색 실응답 미검증 — 로컬에 `KAKAO_REST_KEY`가 없어 폴백만 확인했다. 배포 환경에서 실제로 뜨는지 봐야 하고, 안 뜨면 더미로 조용히 폴백돼 겉보기엔 정상이다
- [ ] 댓글을 연속으로 등록하면 두 번째부터 스크린리더가 안 읽는다 — 알림 문자열이 같아 DOM 변화가 없음. 등록마다 리셋하거나 카운터를 병기
- [ ] 시드 날짜가 UTC 기준이라 KST 00~09시엔 「오늘」이 하루 어긋난다. 서버·클라가 같은 UTC라 라벨끼리는 일관되지만, 실 API 전환 전까지 남는 흠
- [ ] 제보왕 동점 정렬이 `localeCompare(…, "ko")` — 서버 ICU와 브라우저 정렬이 드물게 달라 동점자 순서가 하이드레이션에서 어긋날 수 있다

## 디자이너 몫으로 넘긴 것

- 빈 상태 화면의 CTA·구성 — 지금은 문구만 있고 행동 버튼이 없다. 무엇을 권할지는 디자이너가 정한다. 시드를 서울 8개 동에만 주도록 바꿔서 **동네를 옮기면 빈 화면을 볼 수 있다**
- 순위 화면의 세부 디자인 — 1·2·3위 표현 방식. 큰 틀만 잡아둔다

## 안 하기로 함

- 야채 신선도를 제보마다 입력받기 — 입력이 늘수록 제보가 줄고 핵심 가치 노력 절약과 상충. 대신 가게 단위로 완료 화면에서 받는다
- 구매 여부 기본값 변경 — 「네, 샀어요」 유지
- 촬영 시 감자·1kg·3000원 프리필 — 더미 데이터라 그대로 둠
- 별점 5점 + 후기 본문 — 서비스가 가격 비교에서 가게 리뷰로 바뀌고, 5점 척도는 모바일에서 누르기 어렵다
- 닉네임 중복 확인 / 행정동 인증 — 백엔드 없음

## 완료 기록 — 2026-07-31 배치 상세 (F06~F10 + 공통)

> 아래 다섯 절은 전부 구현·푸시됐다. 근거를 남겨두려고 항목을 보존한다 —
> 되돌리려는 사람이 왜 이렇게 했는지 먼저 읽게 하기 위해서다.

### 공통

**결정된 것**
- [x] **「싸다」 기준을 공공 시세로 통일** — 지금 가게 상세는 공공 시세 대비, 즉석 판단은 동네 최저 제보가 대비다. 같은 가격이 한 화면에선 싸다, 다른 화면에선 비싸다로 나온다. `judgement.ts`의 동네 최저 우선 로직을 공공 시세 기준으로 바꾸고 `detail-features.md` 「즉석 판단」 판정 기준도 함께 고친다
- [x] **색 규칙 고정** — 초록=싸다 전용 / 빨강=비싸다 전용(가게·가게 상세도 회색 대신 빨강) / 주황=신뢰도 전용. 교차검증·오늘 제보는 무채색 배지로. 지금은 초록이 3가지 뜻(싸다·오늘 제보·교차검증)이라 가게 상세 한 줄에 「이웃 2명 확인」과 「시세 −5%」가 같은 초록으로 나란히 뜬다
- [x] **시드 제보 날짜를 오늘 기준 상대값으로** — `ANCHOR_DATE = 2026-07-24` 고정이라 8일째부터 전 화면이 「오래된 가격」 경고색으로 뒤덮인다
- [x] **시드를 서울 주요 동에만 부여** — 지금은 어느 동네든 46종 × 2~3건을 자동 생성해 **빈 화면을 볼 방법이 없다**. 랭킹·가게·가게 상세·댓글 빈 상태가 전부 도달 불가. 동네를 바꾸면 빈 화면이 나오게 남겨둔다

**용어·포맷 통일**
- [x] 시세 대비 표기 4종 → 하나로. 「시세 −12%」 / 「시세보다 20%↓」 / 「시세 대비 500원(+1.2%)」 / 「오늘 시세보다 500원 저렴」
- [x] 기준선 이름 4종 → 하나로. 「시세」 / 「오늘 시세」 / 「오늘 공공 시세」 / 「공공 시세(KAMIS)」. 즉석 판단 한 화면 안에서만 3종이 쓰인다
- [x] 「제보」 단위 혼용 — 「제보 N개 품목」(품목 종수) vs 「제보 N건」(제보 수)
- [x] 퍼센트 부호 4종(`+/−`, `↓`, `▼`, 괄호), 소수점 자릿수(1자리 vs 정수), 원 표기(`formatWon` vs 손으로 조립), 단위 슬래시 공백 3종
- [x] 날짜 표기 — 제보는 상대(「3일 전」), 댓글은 절대(「26.07.24」). 가게 상세 한 화면에 둘이 공존해 어느 쪽이 최신인지 대조가 안 됨
- [x] 더미인데 「예시」 표기가 없는 화면 — 랭킹·카드뉴스. 홈·시세는 표기함

**전 화면 반복**
- [x] 클라 스토어 화면(랭킹·가게·가게 상세·판단)에서 **빈 상태가 먼저 깜빡인 뒤 목록이 나타남**. 서버 스냅샷이 빈 배열이라 로딩과 빈 상태가 구분 안 됨
- [x] **에러가 빈 상태로 위장** — localStorage 파싱 실패 시 `[]`를 반환해 "제보 없음"으로 보인다
- [x] `EmptyState` 컴포넌트가 있는데 랭킹·가게는 클래스까지 복붙
- [x] 화살표 기호 접근성이 절반만 적용 — `trend-label`·`report-list`는 `aria-hidden`+대체문구, 랭킹·카드뉴스·제철추천은 없음
- [x] `text-[28px]` arbitrary value 3곳 반복(랭킹·카드뉴스·제철추천). `VegetableThumb`가 이미 그 역할
- [x] 조사 하드코딩 — 「양파은 지금 시세 데이터가 없어요」

### F06 랭킹 — 제보왕 단독으로 재편

- [x] 탭 3개 제거하고 **제보왕만** 남김. 싼 가게는 가게(F07)으로, 최저가 품목은 홈으로
- [x] **제보에 닉네임 필드 추가** → 제보왕 실데이터화. 내가 제보하면 순위가 오르고, 시드 제보엔 이웃 닉네임 부여. **본명은 쓰지 않는다** — 공개되는 값은 닉네임·아바타·순위·건수까지
- [x] **공개 제보 목록 화면(F06-1) 신설** — 제보왕에서 사람을 누르면 진입. 상단에 닉네임·아바타·순위·건수, 아래에 그 사람 제보 목록(품목·가격·가게·시점). **구매 여부나 절약액 같은 개인 정보는 빼고** 공개 가능한 것만. 지금은 마이페이지 「내 제보」(내 것만)뿐이라 목적지가 없다
- [x] **순위다운 디자인** — 지금은 1위와 4위 렌더가 같고 순위 숫자가 회색이라 이름보다 뒤로 물러난다. 큰 틀만 잡고 세부는 디자이너가 다듬는다
- [x] 위계 역전 — 닉네임 16px/600 > 제보 건수 14px muted. 리더보드의 비교값은 건수
- [x] `h2`가 하나도 없음. h1 다음이 바로 12px 캡션이라 가게 탭과 구조가 다름
- [x] 제보왕 행이 카드처럼 생겼는데 안 눌림 — 다른 화면에선 같은 생김새가 링크다

### F07 가게

- [x] **낡은 제보(7일 초과)를 순위 평균에서 제외** — 화면엔 「오래된 가격」이라고 경고하면서 계산엔 같은 무게로 넣어 경고와 순위가 모순
- [x] **순위 재번호 버그** — 단골로 등록한 가게가 목록에서 빠지고 남은 것에 1번부터 다시 매긴다. 실제 1위를 단골 등록하면 2위가 「1」로 표시됨
- [x] 위계 역전 — 가게 이름 16px/600 > 시세 대비 14px/500. 순위 목록인데 정렬 기준값이 이름보다 작다
- [x] 한 줄에 정보 6개. 거리와 도보 시간은 같은 사실의 두 표현(좌표가 해시 생성값이라 정밀도도 없음), 「제보 N개 품목」은 12px muted라 안 읽히고 정렬에도 1차로 안 쓰임
- [x] **신뢰 신호가 목록에 없다** — 교차검증 수가 계산되는데 렌더되지 않아 **제보 1건짜리 가게가 20건짜리 위에 같은 무게로 1위**로 뜬다
- [x] 로딩 중 다른 동네 사용자에게 **삼성동 목록이 표시**됨. `loading`을 제목에만 쓰고 목록 분기엔 안 씀
- [x] `avgDiffPct === 0`이면 「시세 +0%」. 0은 부호가 없어야 함
- [x] 다른 동네로 옮기면 **단골이 화면에서 사라짐** — 저장은 가게 이름 배열 하나라 **데이터는 보존된다.** 화면에서만 현재 동 제보와 교집합을 잡아 안 보이는 것. 「다른 동네 단골 N곳」 같은 접힌 줄로 알려줘 잃은 줄 알게 하지 않는다

### F09 가게 상세

- [x] **가게 신선도 후기 요약 노출** — 저장만 되고 화면에 없다. 요약 한 줄(좋아요 N·보통 N)로, 한마디는 댓글에 섞어 시간순
- [x] **없는 가게명으로 들어와도 정상 가게처럼 보임** — 지도·주소까지 그려진다. 「찾을 수 없는 가게」로 분기
- [x] **지도 미렌더 시 회색 박스 폴백** — 앱키가 없으면 지금은 아무 표시 없는 빈 영역이 남는다
- [x] 시세 차이가 12px 회색 — 이 화면의 결론인데 줄에서 제일 작다. 14px + 색·아이콘 + **절대 금액(원)**으로. 「시세 −8%」만으론 500원인지 3,000원인지 모름
- [x] 「가장 최근 제보 N일 전」이 **틀린 문장** — 목록이 가격순 정렬이라 `items[0]`은 최근이 아니라 가장 싼 품목이다
- [x] **이상치가 목록 맨 위** — 정렬이 이상치를 제외하지 않아 초저가 오타 제보가 1위로 온다. 반면 요약은 이상치를 빼고 세서 **요약과 목록이 서로 반박**한다
- [x] 제보 1건뿐인 가게도 「1개가 시세보다 싸요」라고 단언 — 근거가 1건이라는 경고 없음
- [x] 「확인 필요」가 무엇을 왜 확인하라는지 없음
- [x] **댓글 작성 권한 게이트** — 지금은 누구나 아무 가게에나 쓸 수 있다. **현재 동네 가게에만 작성 가능**하게 하고, 다른 동네 가게는 읽기만. 「동네 댓글」이라는 이름과도 맞는다
- [x] 댓글 등록 버튼 40px
- [x] 댓글 등록·단골 토글 후 알림 없음(라이브 리전 부재)

### F10 즉석 판단

- [x] **판정 카드를 가격 입력칸 위로** — 키보드가 뜨면 입력칸 아래의 판정이 화면 밖으로 밀려 **타이핑하면서 결과를 볼 수 없다.** 3초 판단이 성립 안 함
- [x] **이상치·오래된 제보를 판정 기준에서 제외** — 장난 제보 1건이 「동네 최저」로 승격해 정상 가격을 전부 비싸다고 판정. 60일 전 제보도 기준이 됨
- [x] 근거 문구 「이웃 제보 N건」이 과장 — 실제로는 그중 **최저 1건**이 판정한다. 게다가 그 이웃에 **내 제보가 섞임**
- [x] **품목을 고르면 그 칩이 사라져 포커스가 날아감** — 검색으로 좁혀 고르면 목록이 인기 8종으로 교체돼, 방금 고른 칩이 없으면 선택 상태가 화면에서 사라진다
- [x] 품목·단위 칩 36px
- [x] 가격 0·비숫자 입력에 무반응 — 입력했는데 「가격을 입력하면 알려드려요」가 그대로. `TextField`의 에러 상태를 안 씀
- [x] 자릿수 오타 방어 없음 — 3,000원 자리에 300,000원을 넣으면 「9900% 비싸요」인데 제목은 「조금 비싸요」
- [x] **시세 없는 품목이 막다른 길** — 「제보해두면 도움이 돼요」라고 권하면서 그 제보 버튼이 비활성
- [x] 단위를 안 골라도 첫 옵션이 **고른 것처럼 표시**됨. 1망 가격이 1kg으로 판정될 수 있음
- [x] `aria-live`가 조건부 마운트라 **첫 판정이 안 읽힐 가능성**. 반대로 마운트 뒤엔 한 글자마다 카드 전체를 재낭독
- [x] 품목 선택 UI를 제보 폼 시트와 **같은 생김새로 통일**(화면은 별개로 유지)
- [x] **제보 시트에서 「가격만 확인」 제거** — 「어떻게 제보할까요?」 안에 제보가 아닌 선택지가 껴 있다. 대신 **시세 화면 위쪽에 판단 버튼 복원**
