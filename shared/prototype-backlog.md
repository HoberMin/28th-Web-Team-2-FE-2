## F05 `/prototype/mypage` (마이페이지)

**구조를 허브형으로 전환한다.** 지금은 섹션 5~6개가 세로로 줄줄이라 스크롤 없이 전체가 안 보인다. 값으로 봐야 하는 것(절약·뱃지)만 남기고, 목록으로 훑는 것은 전부 메뉴 뒤로 보낸다.

```
[프로필]  닉네임 · 삼성동                    ⚙️
[절약 카드]  이번 주 3,200원 아꼈어요   (토글: 이번 주 / 전체)
[뱃지]  🏅🏅🏅

🥕 찜한 야채          12개  ›
📝 내 제보            34건  ›
🧾 구매                8건  ›
🏪 단골 가게           3곳  ›
🔔 매장 알림       2개 켜짐  ›
```

- 아이콘 그리드(카카오 더보기식)가 아니라 **리스트 메뉴**인 이유: 항목이 6개뿐이라 그리드는 허전하고 **개수를 못 보여준다**. 리스트는 눌러보기 전에 "찜 12개"가 읽힌다. 항목이 늘면 그때 그리드로.
- 절약 카드를 허브에 남기는 이유: 핵심 가치가 "눈으로 보는 변화"인데 메뉴 뒤로 숨기면 마이페이지에 들어올 이유가 없어진다.
- 대가: 탭이 사라져 찜↔제보 전환이 1탭에서 2탭이 된다. 마이페이지는 자주 오가는 화면이 아니라 감수한다.

구조 변경
- [ ] 탭 3개(찜/제보/구매) → **리스트 메뉴 + 개별 화면 4개 신설** (찜한 야채 / 내 제보 / 구매 / 단골 가게). **`shared/pages.md` 갱신 포함**
- [ ] **설정 화면(F05-1) 신설** — 우상단 톱니. 계정(닉네임 변경·동네 변경·프로필 이미지) / 알림 전체 on-off / 약관·개인정보·버전·문의 / 로그아웃·탈퇴. 지금은 회원 관리가 통째로 없음

- [ ] **절약 카드 2장을 1장으로 + 기간 토글**(이번 주 / 전체) — 「지금까지 시세 대비 N원」(`head2-20`)과 「이번 주 절약 N원」(`body-14`)이 같은 지표를 기간만 바꿔 두 번 말함
