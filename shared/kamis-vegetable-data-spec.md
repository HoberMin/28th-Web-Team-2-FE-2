KAMIS 채소 데이터 규격 v3, 2026-07-29

원본 코드표: `shared/농축수산물 품목 및 등급 코드표.xlsx` (KAMIS 배포본). 아래 표는 그 원본에서 이 서비스 스코프만 추린 것이고, 코드값이 어긋나면 원본이 우선한다.
기능 단위 정의는 → `detail-features.md`

스코프: 채소류 + 특용작물. 축산물, 수산물 제외. 과일류는 원칙적으로 제외하되 수박·참외·멜론·딸기는 KAMIS 자체가 채소류로 분류하고 데이터 규격상 문제도 없어 포함.

용어

- itemCode(품목코드): 무엇을 파는지 구분하는 코드. 감자, 오이처럼 품목 하나하나에 붙는 고유 번호
- kindCode(품종코드): 같은 품목 안에서 어떤 종류인지 구분하는 하위 코드. 감자 안의 수미, 대지마 같은 것. 가격 조회 시 itemCode만으로는 안 되고 kindCode까지 지정해야 나옴
- productrankcode(등급코드): 상품, 중품, 하품 같은 품질 등급

API 파라미터, 매 요청 4개 전부 명시

- p_itemcategorycode: 100 또는 200
- p_itemcode: 아래 표
- p_kindcode: 아래 표. 배추 무는 예외
- p_productrankcode: 04(상품) 고정. 스코프 전 품목에서 연중 존재함을 실측 확인했고, 감자로 04와 05(중품)를 비교했을 때 05 쪽이 표본이 얇아 며칠씩 값이 안 바뀌는 등 데이터 품질이 낮았음. 상품 등급이 상식적으로도 맞고 데이터 품질도 더 나음

단위 정책

- kg 단위 품목: p_convert_kg_yn=Y
- 개수 포기 단위 품목: p_convert_kg_yn=N, 소비자가 실제로 그 단위로 사는 경우만
- 오이는 개수 단위(kg 환산 안 됨, Y/N 결과 동일 확인)

버그 수정

- 당근 itemCode 246 → 232
- 당근 kindCode 00 → 01
- 피망 itemCode 256 → 255
- 오이 unit 1kg → 개수 단위
- 호박 → 애호박/쥬키니 분리
- 방울토마토 신규 추가
- Vegetable 타입에 kindCode 필드 추가
- kamis.ts에 kindcode, productrankcode 파라미터 추가

배제된 항목과 사유

- 옥수수 - itemCode 자체가 KAMIS에 존재하지 않음(292는 없는 코드)
- 당근 - 당근-일반(00), 세척당근(02), 세척당근-수입(10) 전부 데이터 없음
- 호박 - 단호박(03) 데이터 없음
- 오이 - 가시계통(01) 일반적인 오이와 괴리 있음, 취청(03)은 단일화 결정으로 대표값(다다기, 02)에 병합
- 양파 - 햇양파(02) 계절 한정 보조 품종, 수입(10) 데이터 희박
- 마늘 - 대서/남도/햇 계열(03, 04, 05, 06) 연중 지속 데이터 없음
- 양송이버섯, 표고버섯 - 소매 데이터 없음
- 들깨(국산 수입 둘 다), 호두, 아몬드 - 소매 데이터 없음
- 참깨-중국, 참깨-인도, 땅콩-수입 - 데이터 없음
- 연근, 우엉, 가지, 부추, 청경채, 케일, 콩나물, 양상추 - 소매 데이터 없음
- 절임배추 - 기본형 및 4개 계절형 전부 데이터 없음
- 브로콜리(261) - 데이터 없는 중복 코드, 280을 대신 채택
