# F01-1 야채 시세 [GNB]

경로 — `/prototype/vegetables`

> 46종 전체를 검색·필터·정렬로 훑는 화면. 품목 하나의 상세는 F03이다.

#### 정책

- 검색어가 있으면 종류 필터를 무시한다. 이름을 아는 사람은 목적지가 이미 정해져 있고, 두 필터가 동시에 걸리면 결과가 왜 비었는지 알 수 없다
- 유사 품목은 화면에서 합치지 않는다. 애호박과 쥬키니, 대파와 쪽파, 적상추와 청상추, 방울토마토와 대추방울토마토, 고춧가루 국산과 중국산
- 비수기 품목은 가격 대신 계절 문구를 보여준다. 값이 없는 게 정상인 품목이 있다
- 시세가 대체값으로 채워졌으면 화면에 그 사실을 밝힌다. 진짜 시세인지는 판단의 전제라 숨기면 안 된다

#### Description

1. 앱바 — "야채 시세"
2. **검색 필드** — 라벨 「야채 검색」을 눈에 보이게 단다. placeholder만 두면 입력 후 이 칸의 용도가 화면에서 사라진다
	- 2-1) placeholder "야채 이름 또는 초성으로 검색 (예: ㄱㅈ)"
	- 2-2) 초성만 입력하면 초성 매칭, 아니면 이름 부분 매칭
3. **정렬 버튼** — 「정렬 · {현재값}」. 누르면 바텀시트에서 가나다순 / 싼 순 / 많이 내린 순
	- 3-1) 종류 칩보다 위계를 낮춘다. 둘 다 칩이면 무엇이 필터고 무엇이 정렬인지 구분이 안 간다
	- 3-2) 정렬을 바꾸면 목록이 다시 12종으로 접힌다
4. **기준 캡션** — 정렬 버튼 오른쪽. "N종 · {기준일}". 대체값이면 "· 예시 데이터"를 붙인다. 검색 중에는 "'{검색어}' 검색 결과 · N종"
5. **종류 칩** — 전체 / 감자·뿌리 / 잎채소 / 열매채소 / 고추 / 양념 / 버섯 / 과채. 가로 스크롤. 검색 중에는 숨긴다
6. **야채 그리드** — 3열. 썸네일 / 이름 / 가격 / 등락
	- 6-1) 기본 12종. 「더보기 · N종 더 보기」로 46종 전체
	- 6-2) 검색 중에는 자르지 않는다. 찾는 게 목적인 화면에서 페이지네이션은 방해다
	- 6-3) 비수기 품목은 가격 자리에 계절 문구
	- 6-4) 등락은 상승 빨강 · 하락 초록(구매자 기준). 화살표만으로 전달하지 않는다
	- 6-5) 0.5% 미만 변화는 변동 없음. 매일 소액에 화살표가 뒤집히면 신호가 아니라 잡음이다

#### 상태 3종

| 상태 | 처리 |
|---|---|
| 로딩 | 시세는 서버에서 조립해 내려온다. 화면 안에 로딩 표시 없음 |
| 에러 | 조회 실패 시 대체값 + "예시 데이터" 표기 |
| 빈 | 검색 결과 0건 "'{검색어}' 검색 결과가 없어요" / 종류 필터 결과 0건 "이 종류에 표시할 야채가 없어요" |
