# F01 홈 [GNB]

경로 — `/prototype`

> 대시보드다. 46종 전체를 훑는 목적은 야채시세 탭(F01-1)이 맡고, 홈은 흩어진 정보를 모아 다음 행동으로 보낸다.

> 「이 가격 사도 될까요?」(즉석 판단)·「단골집 오늘 가격」·「{월}월에 사기 좋은 야채」·찜한 가게 미니 목록은 화면에서 없어졌다.
> 제보·찜은 localStorage에 있어 위치 로딩이 끝난 뒤 클라이언트에서 그려진다. 「이번 주 시세 이야기」의 글 3건은 하드코딩 더미다.

#### 정책

- 조건을 못 채운 섹션은 자리를 비워두지 않고 아예 그리지 않는다. 제보를 한 번이라도 했으면 첫 제보 안내가 사라지고, 시세보다 싼 제보가 없으면 「이 가게 어때요?」와 「우리 동네 최저가 야채」가 함께 사라진다
- 위치를 확인하는 동안에는 동네 기반 섹션(「이 가게 어때요?」·「우리 동네 최저가 야채」)을 그리지 않는다. 기본 동네로 만든 목록이 다른 동네 사용자에게 스치면 안 된다
- 「이 가게 어때요?」는 현 위치에서 가까운 가게 3곳으로 후보를 먼저 자르고, 그중 공공 시세보다 싼 품목이 가장 많은 한 곳만 고른다. 아무리 싸도 멀면 안 가기 때문에 "싼 집 1위"가 아니라 "갈 만한 거리 안에서 가장 싼 집"이 답이다
- 「우리 동네 최저가 야채」는 이름과 집계 기간을 맞춘다. 일주일치 제보를 보므로 캡션도 "일주일 동안 이웃이 제보한 가격"이다. 제보가 매일 쏟아지는 서비스가 아니라 하루로 자르면 목록이 거의 빈다
- 한 줄에 초록을 두 번 쓰지 않는다. 가격은 진한 그레이, 초록은 할인폭 한 곳만 맡는다. 값과 할인폭이 모두 초록이면 목록 전체가 초록으로 덮여 "싼 정도"의 차이가 안 읽힌다
- 카드뉴스는 자동 롤링하지 않는다. 글이 3개뿐이라 얻을 게 없고 정지 버튼 UI만 늘어난다
- 카드뉴스는 "지금 뭘 해야 하나"가 아니라 둘러보기라서 화면 맨 아래에 둔다
- 시세는 하루 한 번 갱신되므로 화면은 1시간 단위로 다시 확인한다(`revalidate = 3600`). 다만 이웃 제보로 만드는 값은 제보가 올라오는 즉시 반영한다. 내가 제보하면 바로 보이는 게 제보 유인이다
- 홈에 촬영 진입은 두지 않는다. 사진은 제보 폼(F04-2) 안의 선택 입력이다

#### Description

세로 순서대로.

1. **상단 줄** — 왼쪽 위치 라벨, 오른쪽 검색 아이콘
	- 1-1) 위치 라벨은 핀 아이콘 + 현재 동네. 위치 확인 중에는 "위치 확인 중…". 누르면 「동네 선택」 시트
	- 1-2) 시트에 등록된 동네(최대 3개) 목록. 현재 동네에는 「현재 동네」 표시
	- 1-3) 「다른 동네 찾기」로 검색 뷰 전환. 새로 고르면 등록 + 즉시 전환
	- 1-4) 검색 뷰에는 「등록된 동네 보기」로 목록으로 되돌아가는 길이 있다. 없으면 시트를 닫았다 다시 여는 수밖에 없다
	- 1-5) 검색 아이콘(라벨 「야채 검색」)을 누르면 그 자리에서 입력칸이 열리고 동네 라벨은 접힌다. 좁은 폭에서 둘을 같이 두면 입력칸이 절반으로 줄어 무엇을 치는 칸인지 안 보인다
	- 1-6) placeholder "야채 이름 또는 초성 (예: ㄱㅈ)". 결과는 품목 최대 8개, 썸네일 + 이름만 준다. 고르면 바로 F03이라 목록에 시세를 또 얹지 않는다
	- 1-7) 검색 빈 상태는 둘로 구분한다. 아직 안 쳤으면 "찾는 야채 이름을 입력해 보세요", 쳤는데 없으면 "‘{검색어}’ 검색 결과가 없어요"
2. **첫 제보 안내** — 내 제보 0건일 때만
	- 2-1) 동네 제보도 0건이면 제목 "{동네} 첫 제보를 남겨보세요" + "우리 동네 가격 기록이 아직 없어요. 첫 제보가 이웃의 기준이 됩니다."
	- 2-2) 동네에 제보가 있으면 제목 "아직 제보를 안 하셨어요" + "{동네} 이웃이 N건 남겼어요. 오늘 본 가격 하나만 알려주시면 이웃의 기준이 됩니다."
	- 2-3) CTA 「가격 하나 알려주기」 → 제보 폼(F04-2)
3. **「이 가게 어때요?」** — 보조 문구 "내 근처 저렴한 야채가 많은 가게를 선정했어요"
	- 3-1) 카드 윗줄 — 가게명 / 거리 / 화살표
	- 3-2) 아랫줄 — "공공 시세보다 저렴한 야채 N가지" + 그 품목 일러스트 최대 4개(이름 함께), 넘치면 「+N」. 개수보다 "무엇이 싼가"가 먼저 읽히게 숫자 대신 그림을 쓴다
	- 3-3) 카드를 누르면 가게 상세(F09)
4. **「우리 동네 최저가 야채」** — 이웃 제보 실집계. 헤더 캡션 "일주일 동안 이웃이 제보한 가격"
	- 4-1) 품목마다 가장 싼 제보 1건만. 같은 품목이 목록을 채우면 순위가 아니라 나열이 된다
	- 4-2) 이상치와 7일 지난 제보는 뺀다
	- 4-3) 시세보다 싼 것만, 할인폭 큰 순
	- 4-4) 줄 구성 — 순위 / 썸네일 / 품목명 · (가게 아이콘 + 가게명) / 가격 · "시세보다 N% 싸요"
	- 4-5) 기본 5개, 목록 끝의 「더보기」로 최대 10개까지 펼치고 「닫기」로 되돌린다. 되돌릴 길이 목록 위에 있으면 다시 위로 올라가야 한다
	- 4-6) 헤더 오른쪽 화살표는 야채시세 탭(F01-1)으로 나가는 문이다. 펼치기(목록 끝)와 화면 이동(헤더)은 다른 행동이라 자리를 갈라 둔다
	- 4-7) 줄을 누르면 그 품목의 F03
5. **「이번 주 시세 이야기」** — 가로 스와이프 캐러셀 + 점 인디케이터. 자동 롤링 없음
	- 5-1) 카드 구성 — 캡션 "이번 주 시세 이야기" / 이모지 + 글 제목 / 오른쪽 "더보기"
	- 5-2) 누른 글의 앵커를 넘겨 F08에서 그 글 위치로 바로 이동한다. 3장 전부 목록 맨 위로 보내면 스와이프한 맥락이 버려진다
6. **GNB** — 홈 / 야채시세 / 동네 가게 / 찜 / 마이페이지
	- 6-1) 현재 탭은 색 하나가 아니라 셋으로 알린다. 채운 아이콘 · 색 · 라벨 굵기(+`aria-current`)
	- 6-2) 브랜드색은 아이콘에만 쓴다. 작은 라벨에 쓰면 대비가 AA에 못 미친다

#### 상태 3종

| 상태 | 처리 |
|---|---|
| 로딩 | `prototype/loading.tsx` 공통 — 폰 프레임 유지 + 스피너 + "오늘 시세를 불러오고 있어요". 위치 확인 중에는 라벨이 "위치 확인 중…"이고 동네 기반 섹션(3·4)은 그리지 않는다 |
| 에러 | 시세 조회(KAMIS)가 실패하면 더미 기준선으로 폴백해 화면을 비우지 않는다. 폴백 사실을 홈에서 밝히지는 않는다 *(미구현 — 야채시세 탭·카드뉴스에만 "예시 데이터" 캡션이 있다)*. 그 밖의 오류는 `prototype/error.tsx` 공통 화면("시세를 불러오지 못했어요" + 「다시 시도」) |
| 빈 | 조건부 섹션(2·3·4)은 각자 사라진다. 셋 다 없으면 상단 줄과 「이번 주 시세 이야기」만 남는다 |
