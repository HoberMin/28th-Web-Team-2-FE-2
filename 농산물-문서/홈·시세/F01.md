# F01 홈 [GNB]

경로 — `/prototype`

> 대시보드다. 46종 전체를 훑는 목적은 야채시세 탭(F01-1)이 맡고, 홈은 흩어진 정보를 모아 다음 행동으로 보낸다.

#### 정책

- 조건을 못 채운 카드는 자리를 비워두지 않고 아예 그리지 않는다. 단골 0개면 단골집 카드가 없고, 제보를 한 번이라도 했으면 첫 제보 안내가 사라진다
- 「오늘 최저가」와 「이번 달 사기 좋은 야채」는 근거가 달라 합치지 않는다. 앞은 오늘 이웃이 실제로 본 값, 뒤는 1년 시세에서 뽑은 계절 저점
- 촬영 진입은 홈에 두지 않는다. 촬영은 제보 흐름(F03-1)에서만
- 시세는 하루 한 번 갱신되므로 화면은 1시간 단위로 다시 확인한다. 다만 이웃 제보로 만드는 값(오늘 최저가)은 제보가 올라오는 즉시 반영한다. 내가 제보하면 바로 보이는 게 제보 유인이다
- 「이번 달 사기 좋은 야채」는 저점권 3위 이내 + 연 최고가 대비 5% 이상 싼 품목만 올린다. 조건을 채운 품목이 없는 달에는 섹션을 그리지 않는다. 아무거나 추천하느니 안 보여주는 게 낫다

#### Description

세로 순서대로.

1. **위치 라벨** — 핀 아이콘 + 현재 동네. 누르면 동네 전환 시트
	- 1-1) 시트에 등록된 동네(최대 3개) 목록. 현재 동네에는 「현재 동네」 표시
	- 1-2) 「다른 동네 찾기」로 검색 뷰 전환. 새로 고르면 등록 + 즉시 전환
	- 1-3) 검색 뷰에서 목록으로 돌아가는 버튼 필요. 없으면 시트를 닫았다 다시 여는 수밖에 없다
2. **「이 가격 사도 될까요?」** — 즉석 판단(F10) 진입. 어두운 배경 + 브랜드색 아이콘. 보조 문구 "가격만 입력하면 우리 동네 기준으로 바로 알려드려요"
3. **첫 제보 안내** — 내 제보 0건일 때만
	- 3-1) 동네 제보도 0건이면 "{동네} 첫 제보를 남겨보세요"
	- 3-2) 동네에 제보가 있으면 "{동네} 이웃이 N건 남겼어요"
	- 3-3) CTA 「가격 하나 알려주기」 → F10
4. **단골집 오늘 가격** — 단골이 있을 때만. 줄마다 가게명 / 품목 수 · 최근 제보 시점 / 시세 대비 평균(싸면 초록). 누르면 가게 상세(F09)
5. **{동네} 오늘 최저가** — 이웃 제보 실집계, 기본 5개
	- 5-1) 품목마다 가장 싼 제보 1건만. 같은 품목이 목록을 채우면 순위가 아니라 나열이 된다
	- 5-2) 이상치와 7일 지난 제보는 뺀다
	- 5-3) 시세보다 싼 것만, 할인폭 큰 순
	- 5-4) 「전체보기」는 페이지 이동이 아니라 같은 자리에서 펼치기
	- 5-5) 줄 구성 — 순위 / 썸네일 / 품목명 · 가게명 / 가격 · "시세보다 N% 싸요"
6. **{월}월에 사기 좋은 야채** — 가로 스크롤. 썸네일 / 이름 / 가격 / "연 최고가보다 N%↓". 우측 상단에 근거 라벨 "1년 시세 기준". 조건을 채운 품목이 없으면 섹션 없음
7. **카드뉴스 캐러셀** — 가로 스와이프 + 점 인디케이터. 자동 롤링 없음. 누른 글로 바로 열린다(앵커)
8. **GNB** — 홈 / 야채시세 / 랭킹 / 동네 가게 / 마이페이지
	- 8-1) 현재 탭은 색 하나가 아니라 세 가지로 알린다. 채운 아이콘 · 색 · 굵기

#### 상태 3종

| 상태 | 처리 |
|---|---|
| 로딩 | 위치 확인 중에는 라벨이 "위치 확인 중…". 이때 「오늘 최저가」는 그리지 않는다. 기본 동네로 만든 목록이 다른 동네 사용자에게 스치면 안 된다 |
| 에러 | 시세 조회에 실패해도 화면을 비우지 않고 대체값을 쓴다. 대체값일 때는 그 사실을 표시 |
| 빈 | 조건부 카드(3·4·5·6)는 각자 사라진다. 셋 다 없으면 위치 · 즉석 판단 · 카드뉴스만 남는다 |
