# F10 즉석 판단

경로 — `/prototype/judge` (`?item={품목id}`로 품목 프리필)

> 가게 가격표 앞에서 3초 안에 끝내는 화면. 품목·단위·가격만 넣으면 사도 되는지 답한다.

#### 정책

- 판정 기준은 오늘 공공 시세 하나. 가게 상세(F09)·가게 목록(F07)과 같은 기준선을 써서, 같은 가격이 화면마다 다르게 판정되는 모순을 없앤다
- 우리 동네 제보가는 화면에 계속 보여주되 판정에는 넣지 않는다. 참고 정보로만 쓴다
- 기준 대비 8% 이상 싸면 초록, 8% 이상 비싸면 빨강, 사이는 노랑
- 시세 데이터가 없는 품목은 판정을 보류한다. 근거 없는 숫자를 만들지 않는다
- 단위를 고르기 전에는 아무 옵션도 골라진 것으로 두지 않는다. 첫 옵션으로 조용히 폴백하면 1망 가격이 1kg으로 판정될 수 있다
- 환산 계수가 없는 단위(단·망·박스·묶음)는 판정하지 않는다. kg·개처럼 기준이 확실한 단위만 판정하고, 나머지는 "이 단위는 아직 기준이 없어 판단하기 어려워요"로 보류한 뒤 제보로 보낸다. 실측 전까지는 틀린 답보다 보류가 낫다
- 판정이 끝나면 그 값 그대로 제보로 넘긴다. 판단하려고 이미 넣은 가격이라 제보 비용이 0이다

#### Description

1. 앱바 — 뒤로가기
2. **품목 선택** — 찜한 야채와 자주 찾는 야채를 먼저, 검색 병행. 시세 화면에서 들어오면 이미 골라져 있다
3. **파는 단위 선택** — 품목 단위에 맞는 후보. kg 품목은 1kg·1단·1망·1박스, 개 품목은 1개·3개 묶음·1봉지
	- 3-1) 환산 계수가 없는 단위는 골라도 판정이 안 나온다. 고르기 전에 그 사실이 보여야 한다
4. **가격 입력** — 입력하는 동안 실시간 판정. 숫자만 받는다
5. **판정 카드** — 결론 → 근거 → 다음 행동 순서
	- 5-1) 색 하나로 전달하지 않는다. 문구가 결론을 그대로 말한다
	- 5-2) 표식은 아이콘. 이모지는 기기·폰트마다 다르게 그려져 통제가 안 된다
	- 5-3) 비교 대상은 항상 공공 시세. 동네 제보 건수는 참고 정보로 구분해 표시
	- 5-4) 참고 건수에서도 이상치와 7일 지난 제보는 뺀다. 판정에 안 쓰여도 화면이 과장된다
	- 5-5) 환산 근거를 문구로 밝힌다
6. **하단 버튼** — 자리를 항상 유지하고 조건이 안 맞으면 비활성. 판정 시점에 버튼이 새로 나타나면 입력 중에 화면이 움직인다
	- 6-1) 「이 가격 제보하기」 → F04-2로 값이 넘어간다

#### 판정 단계별 화면

| 입력 상태 | 화면 |
|---|---|
| 품목 미선택 | 판정 자리는 비우고 품목부터 고르게 |
| 단위 미선택 | 단위를 고르라는 안내 |
| 가격 미입력 | 가격을 넣으라는 안내 |
| 시세 없는 품목 | 판정 보류 + 제보 유도. 비수기면 계절 문구 |
| 환산 계수 없는 단위 | 판정 보류 — "이 단위는 아직 기준이 없어 판단하기 어려워요" + 제보 유도 |
| 판정 완료 | 판정 카드 + 제보 버튼 활성 |

#### 상태 3종

| 상태 | 처리 |
|---|---|
| 로딩 | 시세는 서버에서 조립해 내려온다. 판정은 즉시 |
| 에러 | 가격에 0이나 문자를 넣으면 입력 오류 표시 |
| 빈 | 위 「판정 단계별 화면」이 빈 상태를 대신한다 |
