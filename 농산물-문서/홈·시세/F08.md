# F08 카드뉴스

경로 — `/prototype/cardnews`

> 그래프는 눌러야 보인다. 이쪽은 가만히 있어도 "요즘 뭐가 싸다"를 알려주는 자리.

#### 정책

- 자동 롤링하지 않는다. 글이 몇 개뿐이라 얻을 게 없고, 읽는 중에 넘어가면 타깃 연령대에 불만이 크다. 자동으로 하려면 정지 버튼을 추가해야 한다
- 글마다 갈 곳이 있어야 한다. "사기 좋은 시기"라고 말해놓고 목적지가 없으면 읽고 끝난다
- 품목을 못 찾는 글은 아예 렌더하지 않는다. 링크만 살아 있으면 눌렀을 때 조용히 홈으로 튕긴다
- 글은 시세 계산으로 자동 생성하는 방향이다. 사람이 매주 쓰는 구조로 만들지 않는다 (생성 방식은 미정 — `question.md`)

#### Description

1. 앱바 — "시세 이야기". 뒤로가기는 홈
2. 기준 캡션 — "{날짜} 기준 · 예시 데이터". "한 달 새 12%"의 기준일을 화면에서 알 수 있어야 한다
3. **글 카드** — 세로 목록
	- 3-1) 썸네일 + 제목 + 한 달 등락(내림 ▼ 초록 / 오름 ▲ 빨강)
	- 3-2) 화살표만으로 전달하지 않는다. 스크린리더에는 "내림, 12%"로 읽힌다
	- 3-3) 본문 두세 줄
	- 3-4) 하단에 "{품목명} 시세 보러 가기" → F03
4. 홈 캐러셀에서 특정 글을 눌러 들어오면 그 글 위치로 바로 이동한다(앵커). 3장 전부 목록 맨 위로 보내면 스와이프한 맥락이 버려진다
