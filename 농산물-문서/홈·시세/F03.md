# F03 야채 시세 (품목 상세)

경로 — `/prototype/price/{품목id}`

> 품목 하나를 판단하는 화면. 46종 목록은 F01-1이다.

#### 정책

- 동네 제보가가 주인공이고 공공 시세는 비교값이다. 공공 시세는 기준선일 뿐 동네에서 실제로 살 수 있는 가격이 아니다
- 동네 제보가를 그래프보다 위에 둔다. 그래프는 참고 자료이고 제보가가 구매 판단의 직접 근거다
- 위쪽 CTA는 판단, 아래쪽 CTA는 제보. 두 목적을 한 버튼에 섞지 않는다
- 우리 동네에 제보가 없으면 빈 화면 대신 가까운 동네 가격을 출처와 함께 보여준다
- 온라인가는 참고용이다. 판단 기준은 오프라인 동네 가격
- 온라인 4채널을 다 보여주되 실측이 아닌 채널은 화면에 「예시」로 밝힌다. 채널을 빼면 화면 규격이 품목마다 달라진다
- 댓글은 이 화면에 없다. 품목별로 흩어지면 밀도가 안 나고, 대화 주제가 품목이 아니라 가게다 → F09

#### Description

1. **앱바** — 뒤로가기는 온 길로 돌아간다. 여러 경로에서 들어오는 화면이라 목적지를 고정하면 오작동한다. 히스토리가 없으면 홈으로
	- 1-1) 우측에 찜 버튼. 아이콘 단독이라 켜짐·꺼짐을 이름표로도 전달
2. **헤더 카드** — 썸네일 + 품목명 + 단위
	- 2-1) 동네 제보가 — 가장 크게
	- 2-2) 오늘 시세 — 아래 작은 비교값. "{날짜} 기준", 대체값이면 "· 예시 데이터"
	- 2-3) 어제 대비 등락
3. **「이 가격 사도 될지 판단해보기」** — F10으로. 품목이 프리필된다
4. **동네 제보가** — 현재 동네 배지 + 카드형 2줄 목록
	- 4-1) 윗줄 가게명 · 가격 / 아랫줄 제보 시점 · 확인 인원 · 시세 대비 차이
	- 4-2) 시세 대비 차이는 가격과 같은 급으로. 사용자가 실제로 훑는 정보다
	- 4-3) 정렬 — 싼 순 / 최신순
	- 4-4) 가게명을 누르면 F09
	- 4-5) 신뢰 표시 3종 → 아래 「제보 신뢰 표시」
	- 4-6) 제보 0건이면 가까운 동네 3곳의 가격을 동네명·최신 가격·시세 차이·최신도와 함께. 우리 동네 값이 아님을 문구로 밝힌다
5. **시세 그래프** — 1주 / 1개월 / 1년 탭. 지점을 누르면 날짜별 가격
	- 5-1) 데이터 없는 구간은 선을 잇지 않고 비운다. 0원과 구분돼야 한다
	- 5-2) 키보드로도 지점 이동. 좌우 화살표로 한 칸, Home·End로 양 끝
6. **월별 최저가 배지** — 1년 월평균 중 최저 달 + 이번 달 대비 하락률. 최저 달이 이번 달보다 안 싸면 숨긴다
7. **온라인가 비교** — 컬리·쿠팡·G마켓·B마트
	- 7-1) 가로 막대. 같은 축에 동네 제보가 기준선을 얹는다(제보가 없으면 오늘 시세)
	- 7-2) 세로 리스트 금지. 온라인끼리만 비교되면 "동네와 온라인 중 어디가 싼가"에 답하지 못한다
	- 7-3) 막대 아래 판매 방식 라벨 한 줄 — 새벽배송·당일배송·오픈마켓·즉시배송, 단서는 배송비 별도·회원가
	- 7-4) 채널을 누르면 해당 몰 검색으로. 상품 딥링크는 코드가 바뀌어 죽는다
	- 7-5) 하단에 오프라인이 기준이고 온라인은 참고임을 명시
	- 7-6) 실측이 아닌 채널에는 「예시」 표기. 현재 컬리만 실측
8. **하단 「오프라인 가격 제보하기」** — 누르면 F03-1 시트

#### 제보 신뢰 표시

목록의 각 제보에 붙는다. F09에도 같은 규칙.

| 신호 | 규칙 |
|---|---|
| 최신도 | 오늘 / 어제 / N일 전. 7일이 넘으면 흐리게 + 오래된 가격임을 명시 |
| 교차 검증 | 같은 가게·같은 품목 제보가 2건 이상이면 확인 인원 표시 |
| 이상치 | 시세의 2배 초과 또는 절반 미만. 지우지 않고 목록 맨 아래로 내리고 확인 필요 표시, 평균 계산에서만 뺀다 |

#### 상태 3종

| 상태 | 처리 |
|---|---|
| 로딩 | 시세는 서버에서 조립. 제보 목록만 클라이언트에서 그린다 |
| 에러 | 시세 조회 실패 시 대체값 + "예시 데이터" 표기. 없는 품목이면 404 |
| 빈 | 제보 0건 → 근처 동네 가격 / 비수기 품목 → 가격 대신 계절 문구 / 그래프 빈 구간 → 선을 끊는다 |
