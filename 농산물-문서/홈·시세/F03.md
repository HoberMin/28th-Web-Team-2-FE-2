# F03 야채 시세 (품목 상세)

경로 — `/prototype/price/{품목id}`

> 품목 하나를 판단하는 화면. 46종 목록은 F01-1이다.

> 상단 「이 가격 사도 될지 판단해보기」(즉석 판단)와 제보방식 선택 시트는 없어졌다. 하단 CTA는 제보 폼으로 직행한다.
> 동네 제보가·온라인가는 더미다. 제보는 localStorage, 온라인가는 수기 엔트리 + 예시 폴백이다.

#### 정책

- 동네 제보가가 주인공이고 공공 시세는 비교값이다. 공공 시세는 기준선일 뿐 동네에서 실제로 살 수 있는 가격이 아니다
- 동네 제보가를 그래프보다 위에 두고 제목도 한 급 위다. 그래프는 참고 자료이고 제보가가 구매 판단의 직접 근거다
- 헤더의 비교값 라벨은 「오늘 시세」 한 마디다. 기준일·데이터 출처는 이 자리의 판단("동네가 싼가")에 쓰이지 않으면서 줄을 두 줄로 밀어냈다. 같은 정보는 그래프 섹션이 갖고 있다
- 우리 동네에 제보가 없으면 빈 화면 대신 가까운 동네 가격을 출처와 함께 보여준다. 헤더의 동네 제보가도 같이 근처 동네 값으로 바꾼다. 표만 바뀌고 헤더가 "아직 없어요"로 남으면 한 화면 안에서 모순으로 읽힌다
- 온라인가는 참고용이다. 판단 기준은 오프라인 동네 가격
- 온라인가는 수기 실측 엔트리가 없는 품목도 예시로 채워 전 품목에 섹션이 뜨게 한다. 품목마다 있다 없다 하면 화면 규격이 안 잡힌다. 대신 예시가 섞였으면 「예시 데이터 포함」으로 밝힌다
- 온라인 채널은 세로 리스트에 싼 순으로 세우고 맨 위에 오프라인 기준선을 한 줄 얹는다. 이 자리의 판단은 "동네보다 싼가" 예/아니오 하나라서 숫자 두 개를 나란히 두면 끝난다
- 몰 링크는 상품 딥링크가 아니라 품목 검색으로 보낸다. 상품 단위 링크는 코드가 바뀌어 죽는다
- 댓글은 이 화면에 없다. 품목별로 흩어지면 밀도가 안 나고, 대화 주제가 품목이 아니라 가게다 → F09
- 이상치 제보는 지우지 않고 목록 맨 아래로 내린다. 색은 쓰지 않고 흐림 + 배지로만 구분한다. 초록(쌈)·빨강(비쌈)만 남겨 색을 2종으로 줄인다

#### Description

1. **앱바** — 제목 없이 뒤로가기와 찜 버튼만. 뒤로가기는 온 길로 돌아간다. 여러 경로에서 들어오는 화면이라 목적지를 고정하면 오작동한다. 히스토리가 없으면 홈으로
	- 1-1) 우측에 찜 버튼. 아이콘 단독이라 켜짐·꺼짐을 이름표(「{품목명} 찜」 / 「{품목명} 찜 해제」)로도 전달한다
2. **헤더 카드** — 큰 썸네일 + 품목명 + 기준 단위
	- 2-1) 「동네 제보가」 — 가장 크게. 우리 동네 제보가 없으면 근처 동네 최신값 + "{동네} 제보 기준" 꼬리표, 그것도 없으면 "아직 없어요"
	- 2-2) 「오늘 시세」 — 구분선 아래 작은 비교값. 라벨은 이 한 마디뿐이다
	- 2-3) 「어제 대비」 — 금액 + 퍼센트 등락. 0.5% 미만은 "-"
3. **동네 제보가** — 헤더에 현재 동 배지(핀 + 동네명)
	- 3-1) 정렬 세그먼트 — 싼 순 / 최신순. 기본은 싼 순("어디가 제일 싼가"가 먼저다)
	- 3-2) 카드 윗줄 — 가게명 + 가격 · 단위. 가게명이 없는 제보는 "가게 미기재"
	- 3-3) 카드 아랫줄 — 제보 시점 · 교차검증 배지 / 시세 대비 차이. 차이는 금액과 퍼센트를 함께 주고 가격과 같은 급으로 둔다. 사용자가 실제로 훑는 정보다
	- 3-4) 가게명을 누르면 F09
	- 3-5) 신뢰 표시 3종 → 아래 「제보 신뢰 표시」
	- 3-6) 기본 3건만 보여주고 「제보 N건 모두 보기」로 펼친다. 펼친 뒤에는 「접기」
	- 3-7) 제보 0건이면 "아직 {동네} 제보가 없어요. 첫 실제가를 제보해 주시면 이웃이 헛걸음하지 않아요."를 두고, 그 아래 "대신 근처 동네 가격을 참고하세요" + 가까운 동네 최대 3곳(동네명 / 제보 시점 · 제보 N건 / 가격 · 단위 · 시세 대비 금액)
4. **시세 그래프** — 제목 "{품목명} 시세" + ⓘ 툴팁 "한국농수산식품유통공사에서 제공한 소매 가격 데이터예요"
	- 4-1) 기간 세그먼트 — 일주일 / 1개월 / 1년. 기간을 바꾸면 선택 지점이 최신으로 돌아간다
	- 4-2) 선 그래프 + 기간 평균 점선. 지점을 누르거나 끌면 그 날짜·가격이 말풍선으로 뜬다
	- 4-3) 키보드로도 지점 이동. 좌우 화살표로 한 칸, Home·End로 양 끝
	- 4-4) x축 라벨은 처음·중간·끝 세 개. 1년은 "7월", 나머지는 "7/24"
	- 4-5) 그래프 아래 「{기간} 평균가」 카드. 세그먼트를 바꾸면 값도 바뀌므로 기간을 라벨에 명시한다
	- 4-6) 데이터 없는 구간은 선을 잇지 않고 비운다. 0원과 구분돼야 한다 *(미구현 — 지금 시리즈는 빈 구간 없이 채워져 온다)*
5. **월별 최저가 배지** — "{N}월이 최근 1년 중 가장 쌌어요 (지금보다 약 N% 저렴)". 1년 월평균 기준이고, 최저 달이 지금보다 안 싸면 숨긴다
6. **온라인가 비교** — 제목 「온라인가 비교」. 예시가 섞였으면 옆에 "예시 데이터 포함"
	- 6-1) 맨 위 기준선 줄 — 「동네 제보가(기준)」, 제보가 없으면 「오늘 시세(기준)」 + 값 · 단위
	- 6-2) 채널 줄은 싼 순. 몰 이름 / 판매 방식 · 단서(새벽배송 · 와우회원가, 오픈마켓 · 배송비 별도, 즉시배송 · 배달비 별도) / 가격 / "기준보다 싸요" 또는 "기준보다 비싸요"
	- 6-3) 색만으로 싼·비싼을 나누지 않는다. 문구를 함께 준다
	- 6-4) 채널 구성은 품목마다 다르다. 수기 엔트리가 있으면 그 목록(컬리·쿠팡·G마켓·B마트 중 일부), 없으면 컬리·쿠팡·G마켓 예시 3개. 실측은 컬리 엔트리뿐이다
	- 6-5) 줄 전체가 링크다. 해당 몰 검색 결과로 새 탭에서 나가고, B마트는 웹 검색이 없어 배민 홈으로 보낸다
	- 6-6) 하단에 오프라인이 기준이고 온라인은 참고임을 명시한다
7. **하단 「오프라인 가격 제보하기」** — 제보 폼(F04-2)으로 직행. 품목이 프리필된다

#### 제보 신뢰 표시

목록의 각 제보에 붙는다. F09에도 같은 규칙.

| 신호 | 규칙 |
|---|---|
| 최신도 | 오늘 / 어제 / N일 전. 며칠부터 오래된 건지는 품목·사람마다 달라 「오래됨」 표기는 두지 않는다. 날짜를 주고 판단은 보는 사람이 한다 |
| 교차 검증 | 같은 가게·같은 품목 제보가 2건 이상이면 「N명 확인」 배지 |
| 이상치 | 시세의 3배 초과 또는 ⅓ 미만. 지우지 않고 목록 맨 아래로 내리고 흐리게 + 「확인 필요」 배지, 집계에서만 뺀다 |
