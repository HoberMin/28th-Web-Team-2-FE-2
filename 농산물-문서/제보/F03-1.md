# F03-1 제보 방식 선택 (바텀시트)

경로 — F03 하단 CTA에서 열리는 시트

#### 정책

- 이 시트는 제보 전용이다. 판단(가격이 괜찮은지 확인)은 제보가 아니라 여기 섞지 않는다. 위=판단, 아래=제보로 역할을 나눈다
- 촬영으로 들어가는 길은 여기 하나뿐이다. 홈에는 촬영 진입이 없다
- 로그인이 필요한 지점이다. 비회원이면 여기서 로그인 시트를 먼저 띄운다(F00-0)

#### Description

1. 시트 제목 — "어떻게 제보할까요?"
2. **「야채 촬영하기」** → F02. 품목이 함께 넘어간다
3. **「직접 입력하기」** → F04-2. 품목이 함께 넘어간다

가게 위치를 묻는 단계는 없다. 두 경로 모두 목적지로 바로 가고, 위치는 제보 폼 안 drawer에서 고른다.

#### 상태 3종

| 상태 | 처리 |
|---|---|
| 로딩 | 없음 |
| 에러 | 없음 |
| 빈 | 없음 |

- 이탈 — F02 또는 F04-2. 시트를 닫으면 F03 그대로
