# F02 야채 촬영

경로 — `/prototype/capture?item={품목id}&method=photo`

#### 정책

- 인식은 가격표 OCR로 간다. 야채 종류를 알아보는 이미지 인식이 아니라 가격표의 숫자를 읽어 가격 칸을 채운다. 품목은 사용자가 고른다
- OCR을 어디서 돌릴지(서버 / 외부 API / 온디바이스)는 백엔드 판단에 맡긴다. 화면은 「읽는 중 → 결과 프리필」만 알면 된다
- 카메라 권한을 거부해도 막다른 길이 아니다. 직접 입력으로 보낸다
- 진입 경로는 F03-1 하나뿐

#### Description

1. **라이브 상태** — 후면 카메라 실시간 화면
	- 1-1) 좌측 상단 닫기 → 원래 보던 품목 시세 화면(F03)으로
	- 1-2) 하단 셔터 버튼
2. **읽는 중 상태** — 셔터를 누르면 현재 화면을 정지시키고 스피너. 끝나면 F04-2로
	- 2-1) 가격표에서 읽어낸 금액이 가격 칸에 미리 채워진다. 품목은 사용자가 고른다
	- 2-2) 숫자를 못 읽었으면 빈 칸으로 넘긴다. 잘못 읽은 값을 채우느니 비우는 게 낫다
3. **오류 상태** — 카메라 권한 거부·미지원. 왜 안 되는지 한 줄 + 「직접 입력하기」

#### 상태 3종

| 상태 | 처리 |
|---|---|
| 로딩 | 읽는 중 — 정지된 화면 위에 스피너 |
| 에러 | 권한 거부·카메라 없음 — 직접 입력으로 유도. OCR 실패는 에러로 보지 않고 빈 칸으로 넘어간다 |
| 빈 | 숫자를 못 읽음 — 가격 칸을 비운 채 F04-2로 |

#### 화면 전환

- 진입 — F03-1 「야채 촬영하기」
- 이탈 — 촬영 완료 → F04-2 (가격 프리필) / 닫기 → F03
