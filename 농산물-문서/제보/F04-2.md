# F04-2 야채 제보 · 폼

경로 — `/prototype/report` (`?item` `?method` `?place` `?price` `?weight`)

#### 정책

- 가게는 카카오맵 검색 결과에서만 고른다. 이름을 직접 타이핑하는 경로는 없다. 오타로 같은 가게가 둘로 갈라지면 가게 축 집계(F07·F09)가 통째로 깨진다
- 목록에 없는 가게(노점·미등록·반경 밖)는 「가게 없이 제보하기」로 받는다. 동 단위로만 기록되고 시세 집계에는 쓰이되 가게 순위(F07)에는 안 들어간다. 제보 자체를 막지 않는다
- 근처 가게 검색 반경은 1km. 동 하나가 대략 이 정도다
- 품목도 시트에서 고른 값만 받는다
- 촬영·즉석 판단에서 넘어온 값은 다시 묻지 않는다
- 구매와 목격을 구분해 받는다. 「샀어요」만 구매 내역·절약 계산에 잡히고, 둘 다 동네 시세에는 기여한다

#### Description

1. 앱바 — 뒤로가기는 원래 보던 품목 시세 화면. 품목을 아직 안 골랐으면 홈
2. 제목 — "야채의 실제 가격을 알려주세요" 류
3. **위치 요약 칩** — 누르면 가게 선택 시트
	- 3-1) 현재 위치 기준 1km 안의 청과·채소가게·과일가게·마트를 거리순으로. 카카오맵 검색 결과
	- 3-2) 목록 아래에 「가게 없이 제보하기」. 고르면 위치가 동 이름으로 채워지고, 제보 목록·내 제보에는 "{동} · 가게 미상"으로 표시된다
	- 3-3) 검색 칸으로 목록을 좁힐 수 있다. 다만 결과에 없는 이름을 새로 만들지는 못한다
	- 3-4) 위치 확인 중 안내는 선택값을 덮지 않고 문구로만
4. **품목 요약 칩** — 누르면 초성 검색 시트. 촬영으로 들어와도 품목은 사용자가 고른다
5. **양 입력** — 단위는 품목별. 즉석 판단에서 왔으면 프리필
6. **가격 입력** — 이 폼에서 가장 큰 필드. 촬영으로 들어왔으면 가격표에서 읽은 금액이 들어와 있다
7. **구매 여부** — 「네, 샀어요」 / 「시세만 봤어요」
8. **확인 버튼** — 하단 고정. 위치·품목·양·가격이 모두 유효할 때만 활성

#### 상태 3종

| 상태 | 처리 |
|---|---|
| 로딩 | 위치 확인 중 — 안내 문구만, 입력값은 그대로. 근처 가게 목록 조회 중에는 시트 안에 로딩 |
| 에러 | 카카오맵 조회 실패 — 「가게 없이 제보하기」는 항상 살아 있어 제보가 막히지 않는다 |
| 빈 | 1km 안에 가게 0건 — "근처에서 가게를 못 찾았어요" + 「가게 없이 제보하기」 |
