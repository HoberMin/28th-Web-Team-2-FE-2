# F04-2 야채 제보 · 폼

경로 — `/prototype/report` (`?item` `?place`)

> 사진은 OCR이 아니라 데모 고정값이다 — 어떤 사진을 넣어도 감자·1·3,000원으로 읽힌다. 사진 파일 자체는 저장하지 않는다(미리보기만).
> `?method` `?price` `?weight`는 코드가 읽지만 지금 이 값을 넘기는 화면이 없다 *(미사용)*.
> 로그인 요구 게이트는 없다 — 비회원도 제보가 끝난다 *(미구현)*.

#### 정책

- 가게는 근처 목록에서 고르는 것이 기본이다. 목록에 없는 가게(노점·미등록·반경 밖)는 시트 안에서 이름을 직접 입력해 받는다. 다만 폼의 위치 값은 시트에서 확정한 값만 채택한다 — 폼 화면에서 자유 편집은 못 한다. 오타로 같은 가게가 둘로 갈라지면 가게 축 집계(F07·F09)가 깨진다
- 위치는 필수다. 가게를 비운 채로는 확인 버튼이 열리지 않는다
- 근처 가게 검색 반경은 2km, 최대 8곳까지 거리순으로 보여준다
- 품목도 시트에서 고른 값만 받는다. 46종 목록의 초성 검색으로 고른다
- 사진은 갈림길이 아니라 이 폼 안의 선택 입력이다. 넣으면 품목·양·가격을 채워주고, 없어도 제보는 완료된다. 사용자가 이미 손으로 적은 값은 덮지 않는다
- 구매 여부는 묻지 않는다. "샀는지"는 동네 시세에 영향이 없다
- 제보는 기기 localStorage에만 쌓인다. 서버 저장은 없다

#### Description

1. 앱바 — 뒤로가기는 고른 품목의 시세 화면. 품목을 아직 안 골랐으면 홈
2. 제목 — "야채의 실제 가격을 알려주세요"
3. **사진 (선택)** — 맨 위. 넣으면 아래 값이 채워지므로 순서상 먼저 온다
	- 3-1) 빈 상태는 카메라 아이콘 + "사진 넣기" 점선 박스. 후면 카메라 촬영 또는 앨범에서 고르기
	- 3-2) 안내 문구 — "사진을 넣으면 품목과 가격을 자동으로 채워드려요"
	- 3-3) 넣으면 미리보기 썸네일 + 우상단 「사진 지우기」 버튼
	- 3-4) 인식 결과로 비어 있는 칸만 채운다. 이미 적어둔 값은 그대로 둔다
	- 3-5) 사진을 넣고 제보하면 그 제보는 사진 제보로 기록된다
4. **위치 요약 칩** — 고르기 전엔 "위치 선택", 고르면 "📍 {가게명}". 누르면 「어디서 보셨나요?」 시트
	- 4-1) "{동} 근처 청과·마트" — 현재 좌표 기준 청과·채소가게·과일가게·마트를 거리순으로. 각 항목에 분류와 거리(m)
	- 4-2) 목록 아래 「목록에 없어요, 직접 입력할게요」 — 누르면 가게 이름 입력 칸이 열리고 「이 위치로 선택」으로 확정한다. 이름이 비면 확정 버튼은 비활성
	- 4-3) 목록을 좁히는 검색 칸은 없다
	- 4-4) 위치 확인 중에는 "위치 확인 중…" 문구만 — 선택값을 덮지 않는다
5. **품목 요약 칩** — 고르기 전엔 "품목 선택", 고르면 "{이모지} {품목명}". 누르면 「무엇을 보셨나요?」 시트. 초성 검색 지원("예: 감자, ㄱㅈ")
6. **양 입력** — 단위는 품목별(kg·개·포기·g). 품목을 고르면 "{품목명}은 {기준단위} 기준으로 비교해요", 고르기 전엔 "먼저 품목을 골라주세요"
7. **가격 입력** — 이 폼에서 가장 큰 필드
8. **확인 버튼** — 하단 고정. 품목·위치·양(0보다 큼)·가격(0보다 큼)이 모두 채워지고 위치 확인이 끝났을 때만 활성. 별도 에러 문구 없이 비활성으로만 안내한다
9. 확인 → 현재 동네·가게명·양·가격을 localStorage에 저장 → 제보 완료(F04-3)로. 가게명을 같이 들고 간다

#### 상태 3종

| 상태 | 처리 |
|---|---|
| 로딩 | 위치 확인 중 — 안내 문구만, 입력값은 그대로. 그 동안 확인 버튼은 비활성. 시트를 열면 목록 자리에 "불러오는 중…" |
| 에러 | 근처 가게 조회 실패·키 미설정 — 에러를 보여주지 않고 조용히 더미 목록으로 폴백한다. 위치 선택이 제보 중간 단계라 여기서 막히면 이탈로 이어진다 |
| 빈 | 근처 가게 0건 — "근처에 등록된 가게가 없어요" + 직접 입력. 품목 검색 0건 — "{검색어}와 일치하는 품목이 없어요" |
