# F00-1 온보딩 · 닉네임

경로 — `/prototype/onboarding`

> F00-1과 F00-2는 라우트가 하나다. 단계는 화면 안에서 전환되고, 단계별 딥링크나 뒤로가기 히스토리는 없다.

#### 정책

- 제보·랭킹·댓글에 공개되는 이름이다. 본명은 쓰지 않는다
- 내 정보(F05-1)에서 언제든 바꾼다. 횟수 제한 없음
- 바꿔도 제보·순위·절약액은 따라온다. 과거 제보에 남은 이름도 새 닉네임으로 바뀐다

#### Description

1. 제목 — "사용할 닉네임을 알려주세요"
2. **닉네임 입력 필드** — placeholder "닉네임". 진입 시 자동 포커스
	- 2-1) 글자수 카운터 `0/10`
	- 2-2) 오류 문구는 입력을 시작한 뒤에만. 빈 화면이 빨갛게 뜨지 않게
3. **확인 버튼** — 형식이 맞을 때만 활성. 비활성이어도 자리는 유지한다(버튼이 새로 나타나면 입력 중 화면이 움직인다)
	- 3-1) 선택 시 중복 확인 → 통과하면 F00-2
	- 3-2) 확인 중에는 버튼 비활성 + 로딩. 중복이면 입력 필드에 인라인 오류
	- 3-3) 키보드 엔터로도 같게
4. 여백 탭 — 입력·버튼 밖을 누르면 키보드를 내린다

#### 오류 문구

| 상황 | 문구 |
|---|---|
| 2자 미만 | 2자 이상 입력해 주세요 |
| 공백·특수문자 포함 | 띄어쓰기 없이 한글, 영문, 숫자만 쓸 수 있어요 |
| 이미 쓰는 닉네임 | 이미 쓰고 있는 닉네임이에요. 다른 이름을 지어 주세요 |
| 금칙어 | 쓸 수 없는 닉네임이에요 |
| 통신 실패 | 잠시 후 다시 시도해 주세요 |

길이·문자 종류는 입력 중 실시간으로, 중복·금칙어는 확인 버튼을 누른 시점에 서버에서 검사한다. 앞뒤 공백은 지우고 보므로 공백만 친 값은 빈 값과 같다.

#### 상태 3종

| 상태 | 처리 |
|---|---|
| 로딩 | 중복 확인 중 — 버튼 비활성 + 로딩. 입력 필드는 잠그지 않는다 |
| 에러 | 형식·중복·금칙어·통신 실패 전부 입력 필드 인라인 문구 |
| 빈 | 초기 상태. 오류로 보지 않고 확인 버튼만 비활성 |

#### 화면 전환

- 진입 — F00-0에서 카카오 로그인한 직후(신규 회원). 둘러보기 사용자가 나중에 로그인해도 여기부터
- 이탈 — 확인(중복 통과) → F00-2
- 뒤로가기 — 없음
