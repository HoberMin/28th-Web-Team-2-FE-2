# F00-2 온보딩 · 지역 선택

경로 — `/prototype/onboarding`

> 이 선택 UI는 세 곳이 공유한다. 온보딩(전체 화면) / 홈 위치 라벨 drawer(F01) / 내 정보 동네 관리(F05-1). 한 곳을 고치면 세 곳이 같이 바뀐다.

#### 정책

- 동네 인증 없음. 실제 거주지가 아니어도 아무 동네나 고를 수 있다
- 동네는 한 번에 하나만 활성. 등록은 최대 3개까지(F05-1)
- 로그인 여부와 무관하게 이 단계는 거친다

#### Description

1. 뒤로 가기 — 입력한 닉네임은 유지된다
2. 제목 — "평소 어디에서 야채를 구매하나요?"
3. **「현재 위치로 찾기」**
	- 3-1) 측위 중 라벨 "위치 확인 중…" + 버튼 비활성
	- 3-2) 성공하면 그 동네를 바로 채택하고 다음 화면으로. 목록만 다시 정렬되고 화면이 안 넘어가면 반응이 없는 걸로 읽힌다
	- 3-3) 실패(권한 거부·타임아웃·미지원)는 버튼 아래 한 줄 — "위치를 확인할 수 없어요. 아래에서 동네를 검색해 주세요"
4. **검색 필드** — placeholder "동 단위로 검색". 부분일치. 검색어를 바꾸면 목록 스크롤이 맨 위로
5. 섹션 라벨 — 검색어 없을 때만
	- 5-1) 위치를 알면 "지금 있는 동네"
	- 5-2) 모르면 "동네 추천"
6. **지역 목록** — 검색어 없으면 가까운 순 4개
	- 6-1) 고르는 즉시 채택하고 다음 화면으로. 확인 버튼 없음
	- 6-2) 최대 높이 45vh 안에서 스크롤(스크롤바 숨김). bottom sheet 안에서도 쓰여서 제한이 없으면 시트가 화면을 넘긴다
7. 빈 결과 — "검색 결과가 없어요"

#### 지역 데이터

| 항목 | 값 |
|---|---|
| 총 개수 | 451개 — 서울 행정동 424 + 경기 주요 동 27 |
| 출처 | 통계청 기준 서울시 행정동 중심점(2017) 실좌표 |
| 정렬 | 중심점 간 거리 근접순 |

이름 충돌 처리 2건, 되돌리지 말 것

- 삼성동 — 행정동은 삼성1동·삼성2동이지만 기준 지역과 시드 제보가 전부 "삼성동"(선릉 일대)이라 하나로 합쳤다. 좌표는 선릉 기준
- 관악구 삼성동 / 강남구·은평구 신사동 — 이름이 겹쳐 구를 앞에 붙였다

측위는 브라우저 위치 권한 → 좌표 → 동네 변환 순서로, 8초 안에 답이 없으면 끊는다. 위치 변환 인증키는 서버까지만 두고 화면 코드에 노출하지 않는다.

#### 상태 3종

| 상태 | 처리 |
|---|---|
| 로딩 | 측위 중 — 버튼 라벨 변경 + 비활성. 스크린리더에 상태 변화 전달 |
| 에러 | 측위 실패 — 버튼 아래 한 줄. 검색 경로는 그대로 |
| 빈 | 검색 결과 0건 |

- 이탈 — 지역 선택·측위 성공 → 홈(F01)
- 뒤로가기 — F00-1 (둘러보기 경로면 F00-0)
