# F00-0 서비스 소개 · 로그인

경로 — `/prototype/intro` *(신규 · 미구현)*

> 앱을 처음 켠 사람이 만나는 화면. 여기서 카카오로 시작하거나 로그인 없이 둘러보기로 갈린다.

#### 정책

- 로그인 없이 시세 조회까지 허용한다. 제보·찜·단골·댓글은 로그인 필요
- 비회원이 고른 동네는 로그인할 때 계정으로 넘어간다
- 카카오 이름을 닉네임으로 가져오지 않는다

#### Description

1. 서비스 소개 — 야채 일러스트 + 한 문장 카피. 예: "우리 동네 야채, 오늘 얼마인지 이웃이 알려줘요" *(문구 미확정)*
2. 핵심 가치 3줄 — 오늘 시세 / 이웃이 본 동네 가격 / 절약액. 1번과 함께 첫 화면에 들어간다
3. **「카카오로 시작하기」** — 주 CTA, 하단 고정. 카카오 디자인 가이드 규격 그대로 쓴다(색·로고·문구를 바꾸면 심사에서 반려)
	- 3-1) 인증 중 버튼 비활성 + 로딩
	- 3-2) 카카오 화면에서 취소하면 에러 없이 이 화면으로 복귀
	- 3-3) 인증 실패는 버튼 아래 한 줄 안내 + 재시도
4. **「먼저 둘러볼게요」** — 텍스트 버튼으로 3번보다 약하게. 선택 시 F00-2로
5. 약관 안내 — "시작하면 이용약관과 개인정보처리방침에 동의한 것으로 봐요". 각각 눌러 볼 수 있게

#### 로그인 요구 시점 (둘러보기 사용자)

바텀시트로 띄운다. 화면을 통째로 막지 않는다.

| 행동 | 화면 |
|---|---|
| 제보하기 | F03-1 / F04-2 |
| 찜하기 | F01-1 / F03 |
| 단골 등록 | F07 / F09 |
| 댓글 쓰기 | F09 |
| 마이페이지 진입 | F05 |

랭킹(F06)과 가게 탭(F07)은 로그인 없이 볼 수 있다. 단골 버튼을 누를 때만 로그인을 요구한다.

- 시트 — 왜 필요한지 한 줄 + 「카카오로 시작하기」 + 닫기
- 로그인하면 원래 하려던 동작으로 돌아온다. 홈으로 튕기지 않는다
- 닉네임이 없으면 F00-1을 먼저 거친다. 동네는 이미 있으니 다시 묻지 않는다

#### 재진입 규칙

각 단계는 통과하는 즉시 저장한다. 앱을 껐다 켜면 멈춘 자리부터 이어간다.

| 지난번에 멈춘 곳 | 다시 켰을 때 |
|---|---|
| 아무것도 안 함 | F00-0 |
| 둘러보기로 동네만 정함 | 홈 |
| 카카오 로그인 후 닉네임 전 이탈 | F00-1 — 카카오 인증을 다시 시키지 않는다 |
| 닉네임까지 하고 동네 전 이탈 | F00-2 |
| 동네까지 정함 | 홈 |

#### 상태 3종

| 상태 | 처리 |
|---|---|
| 로딩 | 카카오 인증 중 — 버튼 비활성 + 로딩 |
| 에러 | 인증 실패·네트워크 오류 — 버튼 아래 한 줄 + 재시도. 취소는 에러 아님 |
| 빈 | 해당 없음 |

#### 화면 전환

- 진입 — 앱 첫 실행
- 카카오 로그인 → 신규면 F00-1 → F00-2 → 홈. 기존 회원은 바로 홈
- 먼저 둘러보기 → F00-2 → 홈
