# F00-0 서비스 소개 · 로그인

경로 — `/prototype/intro` *(2026-08-05 코드 기준 재검토)*

> 앱을 처음 켠 사람이 만나는 화면. 여기서 카카오로 시작하거나 로그인 없이 둘러보기로 갈린다.
> 로그인은 실제 OAuth가 아니라 목업이다 — `_lib/kakao-auth.ts`가 잠깐 기다린 뒤 **항상 신규 회원으로 성공**한다. 취소·실패 경로는 목업에 없다.
> 「로그인 요구 시점」 바텀시트는 아직 없다. 지금은 둘러보기 사용자도 제보·찜·댓글·마이페이지를 전부 쓴다.

#### 정책

- 로그인 없이 시세 조회까지 허용하고, 제보·찜·댓글은 로그인을 요구한다 *(미구현 — 게이트가 없어 비회원도 전부 된다)*
- 비회원이 고른 동네는 로그인해도 그대로 이어진다. 계정 서버가 없어 기기 저장값(`veg-onboarding-v1`) 하나를 계속 쓴다
- 카카오 이름을 닉네임으로 가져오지 않는다. 목업 응답에 프로필이 없는 게 정상이다

#### Description

1. 히어로 — 야채 일러스트 3종(토마토·당근·양파)이 느리게 둥실거린다. 장식이라 스크린리더에서 감추고, reduced-motion이면 멈춘다
2. 제목 — "우리 동네 야채, 오늘 얼마인지 이웃이 알려줘요". 쉼표 뒤에서 줄을 끊어 두 줄로 고정한다
3. 핵심 가치 3줄 — 아이콘도 야채 일러스트를 재사용한다
	- 3-1) "오늘 시세 / 야채 46종, 매일 새로 확인해요"
	- 3-2) "이웃이 본 동네 가격 / 우리 동네 가게에서 실제로 본 가격이에요"
	- 3-3) "아낀 금액 / 얼마나 덜 냈는지 쌓아서 보여줘요" — 이 줄이 가리키는 절약액 지표는 마이페이지에서 걷어냈다(구매 개념 폐기). 소개가 화면에 없는 걸 약속하고 있어 문구 정리가 필요하다 → `question.md`
4. **「카카오로 시작하기」** — 주 CTA, 하단 고정. 카카오 브랜드 규격(색·검정 로고·문구) 그대로 쓴다. 바꾸면 심사에서 반려된다
	- 4-1) 진행 중엔 라벨이 "카카오 로그인 중…"으로 바뀌고 버튼 두 개가 같이 비활성
	- 4-2) 성공하면 회원 상태를 즉시 저장한 뒤 신규는 `/prototype/onboarding`, 기존 회원은 홈으로 보낸다. 목업은 항상 신규다
	- 4-3) 실패 문구는 "로그인하지 못했어요. 잠시 후 다시 시도해 주세요" — 버튼 아래 한 줄, 다시 누르면 재시도. 목업엔 실패·취소가 없어 실제로는 뜨지 않는다 *(미구현)*
5. **「먼저 둘러볼게요」** — 밑줄 텍스트 버튼으로 4번보다 약하게. 누르면 비회원으로 저장하고 온보딩으로 가는데, **닉네임 단계를 건너뛰고 지역 선택(F00-2)부터** 시작한다
6. 약관 안내 — "시작하면 이용약관과 개인정보처리방침에 동의한 것으로 봐요". 두 단어가 각각 버튼이고, 누르면 "약관 문서는 아직 준비 중이에요" 한 줄이 붙는다. 약관 원문은 프로토타입에 없어 죽은 링크를 만들지 않았다

#### 로그인 요구 시점 (둘러보기 사용자) *(미구현 — 설계 의도로만 유지)*

바텀시트로 띄운다. 화면을 통째로 막지 않는다.

| 행동 | 화면 |
|---|---|
| 제보하기 | F04-2 |
| 찜하기 | F01-1 / F03 |
| 찜한 가게 등록 | F07 / F09 |
| 댓글 쓰기 | F09 |
| 마이페이지 진입 | F05 |

- 시트 — 왜 필요한지 한 줄 + 「카카오로 시작하기」 + 닫기
- 로그인하면 원래 하려던 동작으로 돌아온다. 홈으로 튕기지 않는다
- 닉네임이 없으면 F00-1을 먼저 거친다. 동네는 이미 있으니 다시 묻지 않는다 *(현재 코드엔 비회원이 나중에 닉네임을 받는 경로가 없다)*

#### 재진입 규칙

각 단계는 통과하는 즉시 저장한다(`_lib/onboarding-store.ts`). 홈에 들어올 때 게이트가 저장값을 읽어 멈춘 자리로 되돌린다.

| 저장 상태 | 보내는 화면 |
|---|---|
| 로그인·둘러보기 미결정 | F00-0 |
| 둘러보기 + 동네 전 이탈 | F00-2 — 닉네임은 묻지 않는다 |
| 카카오 로그인 후 닉네임 전 이탈 | F00-1 — 카카오 인증을 다시 시키지 않는다 |
| 닉네임까지 하고 동네 전 이탈 | F00-2 |
| 동네까지 정함(완료) | 홈 |

- `/prototype/onboarding`에 바로 들어와도 회원·비회원이 정해지지 않았으면 F00-0으로 되돌린다
- 저장값 마이그레이션 — 이 화면이 생기기 전에 온보딩을 마친 사람은 카카오 회원으로 간주한다. 안 그러면 기존 사용자가 전부 소개 화면으로 튕긴다
- 마이페이지 로그아웃은 회원 상태만 비워 이 화면으로 되돌린다. 찜·제보 같은 기기 데이터는 남는다(지우는 건 탈퇴의 역할)

#### 상태 3종

| 상태 | 처리 |
|---|---|
| 로딩 | 카카오 인증 중 — 버튼 라벨 변경 + 두 버튼 비활성 |
| 에러 | 인증 실패 — 버튼 아래 한 줄 + 재시도. 취소는 에러 아님 *(목업엔 두 경로 모두 없음)* |
| 빈 | 해당 없음 |

#### 화면 전환

- 진입 — 앱 첫 실행, 또는 홈 게이트가 미완료 상태를 감지했을 때. 로그아웃·탈퇴 후에도 여기로
- 카카오 로그인 → 신규면 F00-1 → F00-2 → 홈. 기존 회원은 바로 홈
- 먼저 둘러볼게요 → F00-2 → 홈
