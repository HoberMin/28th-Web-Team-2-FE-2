# 질문 목록

2026-08-05 기준. **프로토타입 코드(`app/prototype/**`)를 진실 소스로 놓고 전면 재검토했다** — 문서가 코드와 다르면 문서를 고쳤고, 삭제된 기능을 전제한 항목은 「해소됨」으로 정리했다.

---

#### 남은 질문 — 데이터·콘텐츠

#### 1. ⚠️ 방울토마토 단위가 정말 「개」인가

코드(`_lib/vegetables.ts`)는 방울토마토·대추방울토마토를 `1개`(unitType `개`)로 두고 기준가를 개당 400원·500원으로 쓴다. 한 알에 400원일 리 없으니 100g 값을 「개」로 이름만 붙인 것일 가능성이 크다. 같은 파일에서 파프리카는 `100g`이라 100g 단위 자체는 쓰이고 있다.

- 먼저 할 일 — KAMIS 응답을 직접 찍어 단위 확인
- `개`가 맞으면 → 화면 표기를 팩(예: 1팩 500g)으로 환산할지 결정
- `100g`이면 → 규격 문서와 코드를 둘 다 고쳐야 한다

#### 2. 1단·1망·1박스 환산 계수 실측

「실측 전까지 판정 보류」로 정해 화면은 안전하지만, 시장에서 실제로 파는 단위가 대부분 이쪽이라 판정이 안 되는 경우가 계속 남는다. 언제 누가 실측할지.

#### 3. 카드뉴스 자동 생성 방법

코드(`_lib/card-news.ts`)는 지금 **고정 더미 3건**이고 기준 시점도 하드코딩이다. 제목 틀만 정해져 있다 — "{품목} 값, 한 달 새 {N}% {내렸어요|올랐어요}". 남은 것은 본문을 어떻게 채우는가.

- A안 — 시세 계산 + 문장 틀 조합
- B안 — LLM으로 문장 생성
- C안 — 틀은 계산, 표현만 생성

#### 남은 질문 — 코드를 읽다 새로 생긴 것

아래는 전부 **질문이다**. 어느 안으로 갈지는 정해지지 않았다.

#### 4. 소개 화면의 「아낀 금액」 문구

F00-0 핵심 가치 3줄 중 세 번째가 "아낀 금액 / 얼마나 덜 냈는지 쌓아서 보여줘요"인데, 절약액 지표는 마이페이지에서 걷어냈다(구매 개념 폐기). 소개가 없는 기능을 약속하고 있다.

- A안 — 문구를 남은 기능으로 교체(예: 제보 스탬프·찜한 야채 알림)
- B안 — 절약액 지표를 되살린다

#### 5. 닉네임 10자 상한을 어떻게 막을까

입력 컴포넌트가 잘라 준 값을 화면이 쓰지 않아 11자 이상도 그대로 들어온다. 카운터는 상한을 넘고, 그때 뜨는 문구는 "2자 이상 입력해 주세요"로 상황과 어긋난다.

- A안 — 잘린 값을 받아 11자 입력 자체를 차단
- B안 — 초과 입력은 허용하고 "10자 이하로 써주세요" 문구를 따로 둔다

#### 6. 닉네임 중복·금칙어 검사

계정 서버가 없어 지금은 검사가 없다. 문구는 F00-1에 후보로 남겨 뒀다.

- A안 — 실서비스 전환 때 확인 버튼 시점에 서버 검사(현 설계 그대로)
- B안 — 프로토타입 기간엔 계속 미검사로 두고 문구도 지운다

#### 7. 비회원에게 닉네임을 언제 받을까

지금 비회원(둘러보기)은 닉네임 단계를 영구히 건너뛰고, 나중에 로그인해도 닉네임을 받는 경로가 없다. 그래서 제보·댓글에 "이웃"으로 남는다.

- A안 — 로그인 요구 시트를 통과한 직후 닉네임 단계
- B안 — 첫 제보를 쓰는 시점에 이름을 묻는다

#### 8. 로그인 요구 게이트를 프로토타입에 넣을까

지금은 게이트가 없어 비회원도 제보·찜·댓글·마이페이지를 전부 쓴다.

- A안 — 지금처럼 전부 개방(UT·디자이너 확인 흐름을 끊지 않는다)
- B안 — 바텀시트를 구현해 회원/비회원 차이를 실제로 보여준다

#### 9. 측위 결과가 지역 목록 밖일 때

역지오코딩이 451개 목록에 없는 동을 돌려주면 실패로 보지 않고 삼성동으로 채택한다. 시드가 없는 동네에서 화면이 비는 걸 막으려던 처리인데, 사용자에게는 엉뚱한 동네로 보인다.

- A안 — 실패로 처리해 검색을 유도(F00-2 실패 문구 재사용)
- B안 — 현행 유지(UT 편의 우선), 대신 안내 한 줄 추가

#### 10. 로그아웃의 정의

코드는 회원 상태만 비워 소개 화면으로 되돌리고 기기 데이터(찜·제보)는 남긴다. 예전 확정값은 "비회원 상태로 (찜·단골 숨김)"였다.

- A안 — 현행 유지(로그아웃 = 재진입 플로우 확인용)
- B안 — 비회원 상태로 전환해 찜·제보를 숨긴다

#### 11. 탈퇴 후 제보를 어떻게 남길까

예전 확정값은 "제보는 「탈퇴한 이웃」으로 남김"인데, 코드는 백엔드가 없어 `veg-` 접두사 저장값을 통째로 지운다(내 제보도 사라진다). 시드 제보만 남는다.

- A안 — 실서비스에서 「탈퇴한 이웃」 처리(현 설계 유지)
- B안 — 기기 데이터 전삭제를 그대로 정책으로 승격

#### 12. 근처 가게 검색 반경 — 1km인가 2km인가

확정값 표는 1km인데 코드(`app/api/nearby-stores`)는 2km로 카카오 로컬을 호출한다.

- A안 — 코드를 1km로 되돌린다(도보 판단 기준에 맞춤)
- B안 — 2km를 확정값으로 승격(청과·마트가 1km 안에 없는 동네가 있다)

#### 13. 이상치 경계 — 2배·절반인가 3배·⅓인가

확정값 표는 "2배 초과 또는 절반 미만"인데 코드(`_lib/stores.ts`)는 3배·⅓로 판정한다. 알림 다이제스트도 코드 기준을 따른다.

- A안 — 코드 기준(3배·⅓)을 확정값으로 승격
- B안 — 2배·절반으로 코드를 좁힌다(오타를 더 많이 걸러낸다)

#### 14. 제철 추천 채택 규칙을 살릴까

확정값은 "저점권 3위 이내 + 연 최고가 대비 5%↓, 없으면 섹션 숨김"인데, 코드(`_lib/cheapest-month.ts`)는 12개월 평균에서 **가장 싼 달 하나**만 계산하고 채택 조건이 없다.

- A안 — 규칙을 코드에 넣는다(조건 미달이면 섹션 숨김)
- B안 — 지금의 단순 최저월 표기를 확정값으로 바꾼다

#### 15. 가짜 지도·해시 좌표를 실좌표로 바꾸는 시점

가게 탭 지도(`stores-map-view.tsx`)는 회색 배경 + 상대 위치 핀이고, 가게 좌표는 동 중심에 가게명 해시 오프셋을 더해 만든다. 가게 상세(`store-map.tsx`)만 카카오 지도 SDK를 실제로 붙인다(JS 앱키 없으면 회색 박스).

- A안 — 제보 저장 시 카카오 장소 좌표를 함께 받아 두 화면 모두 실좌표로
- B안 — 프로토타입 기간엔 현행 유지(가게 탭은 계속 가짜 배경)

#### 16. localStorage → BFF 이관 범위

클라 데이터가 전부 `veg-*` localStorage다(온보딩·제보·찜·찜한 가게·댓글·가게 리뷰·알림). 실서비스 전환 때 어디까지 서버로 올릴지.

- A안 — 계정에 묶이는 것만(온보딩·제보·찜·댓글) 서버, 알림 설정은 기기에 남김
- B안 — 전부 서버로 올리고 localStorage는 캐시로만

#### 17. 찜한 가게 진입점 중복

GNB 「찜」 탭에 야채·가게 두 목록이 있는데, 마이페이지에도 「찜한 가게」 메뉴가 따로 있다(`/prototype/mypage/stores`).

- A안 — 마이페이지 메뉴를 지우고 찜 탭 하나로
- B안 — 둘 다 두고 마이페이지 쪽은 「내 제보」와 짝으로 유지

#### 참고 — 미룬 것

- 지도 앱키 — 카카오 JS 앱키가 없으면 가게 상세 지도는 회색 박스로 자리만 잡는다. 거리·주소는 항상 텍스트로 전달
- 심부름 목록 — 이번 파도에서는 안 봄
- 가게 비공개 요청 창구 — 일단 공개로 가고 문제가 생기면 대응
- 허위 제보 신고 버튼 — 안 넣음. 이상치 자동 표시로 갈음
- 약관 별도 동의 화면 — 로그인 아래 한 줄로 갈음. 약관 원문이 없어 누르면 "준비 중" 안내만 뜬다. 출시 전 법무 재확인
- 제보 어뷰징 — **해소됨(기능 삭제)**. 제보왕·랭킹을 걷어내 순위를 올릴 동기 자체가 없어졌다
- 홈 「찜한 가게 오늘 가격」 존치 — **해소됨**. 홈의 미니 목록 카드를 걷어내고 「동네 가게」·찜 탭으로 모았다
