#### 남은 질문 4개

#### 1. ⚠️ 방울토마토 단위가 정말 「개」인가

레포 두 곳(규격 문서·코드)이 전부 `개`로 적고 있는데, 값이 개당 400원(대추방울 500원)이다. 방울토마토 한 알이 400원일 리 없으니 실제로는 100g 값을 개 단위로 이름만 붙여 놓았을 가능성이 크다. 같은 파일에서 파프리카는 `100g`으로 돼 있어 100g 단위 자체는 쓰이고 있다.

- 먼저 할 일 — KAMIS 응답을 직접 찍어 단위를 확인
- `개`가 맞으면 → 화면 표기를 팩(예: 1팩 500g)으로 환산할지 결정
- `100g`이면 → 규격 문서와 코드를 둘 다 고쳐야 함. 틀린 단위로 판정하면 신호등이 통째로 틀린다

#### 2. 1단·1망·1박스 환산 계수 실측

「실측 전까지 판정 보류」로 정했으므로 화면은 안전해졌지만, 시장에서 실제로 파는 단위가 대부분 이쪽이라 판정이 안 되는 경우가 계속 남는다. 언제 누가 실측할지.

#### 3. 카드뉴스 자동 생성 방법

방향은 자동으로 정했다. 남은 것은 어떻게 만들 것인가.

- 시세 계산 + 문장 틀 조합 (예: "{품목}, 한 달 새 {N}% 내렸어요")
- LLM으로 문장 생성
- 둘 다 — 틀은 계산, 표현만 생성

#### 4. 홈 「단골집 오늘 가격」 존치

가게 탭(F07) 상단 「내 단골 가게」와 축이 같다. "어느 화면에서 어떤 데이터를 보여줄지"를 나중에 한 번에 정리하기로 미뤄둔 항목.

- 제보 어뷰징 — 제보왕 순위를 올리려고 같은 가게·같은 품목을 반복 제보하는 걸 지금은 막지 않는다. 순위 조작이 실제로 보이면 그때 「같은 조합 하루 1회」를 건다

- 지도 앱키 — 발급 전. 그동안 F09는 지도 없이 주소·도보 시간만
- 심부름 목록 — 이번 파도에서는 안 봄
- 가게 비공개 요청 창구 — 일단 공개로 가고 문제가 생기면 대응
- 허위 제보 신고 버튼 — 안 넣음. 이상치 자동 표시로 갈음
- 약관 별도 동의 화면 — 로그인 아래 한 줄로 갈음. 출시 전 법무 재확인

#### 확정된 값 (한눈에)

| 항목 | 값 |
|---|---|
| 신호등 판정 경계 | 시세 대비 ±8% |
| 이상치 | 시세의 2배 초과 또는 절반 미만 |
| 오래된 제보 | 7일 |
| 알림 하락 임계 | 최근 30일 평균 대비 10% |
| 근처 가게 검색 반경 | 1km |
| 제철 추천 채택 | 저점권 3위 이내 + 연 최고가 대비 5%↓, 없으면 섹션 숨김 |
| 절약 카드 「이번 주」 | 최근 7일 |
| 집계 주기 | 제보 즉시 (가게 순위·오늘 최저가·제보왕 공통) |
| 동네 등록 | 최대 3개, 활성은 항상 1개 |
| 가게 입력 | 카카오맵 검색 결과에서만 선택. 없으면 「가게 없이 제보하기」 |
| 제보 수정 | 덮어쓰기, 이력 없음 |
| 탈퇴 | 제보는 「탈퇴한 이웃」으로 남김 |
| 로그아웃 | 비회원 상태로 (찜·단골 숨김) |
| 비회원 조회 범위 | 홈·야채시세·품목 상세·랭킹·가게까지. 마이페이지만 로그인 |
| 교차검증 | 같은 가게·같은 품목 2건부터 「이웃 확인」 표시 |
| 촬영 인식 | 가격표 OCR로 가격만. 품목은 사용자가 고른다 |
| 온보딩 완료 화면 | 없음. 동네를 고르면 바로 홈 |
