# F05-1 마이페이지 · 내 정보

경로 — `/prototype/mypage/settings`

#### 정책

- 알림은 전역 토글 하나뿐이다. 품목별·가게별 개별 토글은 두지 않는다. 알림 대상은 별도 등록 없이 찜한 야채와 단골 가게가 된다
- 개별 끄기가 없으므로 트리거 기준이 볼륨을 관리하는 유일한 장치다. 이 기준이 헐거우면 사용자에게는 전체를 끄는 선택지밖에 없다
- 건건이 보내지 않고 하루 한 번 묶어서 보낸다
- 이상치 제보는 알림 집계에서 뺀다. 오타 제보 하나가 알림으로 울리면 안 된다
- 설정을 마이페이지 본문에 쌓지 않고 별도 화면으로 뺀다. 한 화면에 두면 내 활동과 계정 관리가 섞인다
- 동네 변경 진입점은 둘로 고정한다. 홈 위치 라벨 drawer가 빠른 전환, 여기가 정식 관리
- 로그아웃하면 비회원 상태가 된다. 찜·단골·제보는 화면에서 사라지고 시세만 보인다. 다시 로그인하면 그대로 돌아온다. 가족이 기기를 함께 써도 남의 기록이 안 보인다
- 탈퇴해도 내가 올린 제보는 남는다. 작성자만 「탈퇴한 이웃」으로 바뀌고 순위에서 빠진다. 제보까지 지우면 이웃이 보던 동네 가격이 통째로 사라진다

#### Description

1. 앱바 — "내 정보"
2. **계정**
	- 2-1) 닉네임 — 현재값(없으면 "미설정"). 누르면 변경 시트. 규칙은 F00-1과 동일
	- 2-2) 동네 — "N개 등록". 누르면 관리 시트. 목록에서 활성 전환·해제, 「동네 추가」로 검색해 추가(최대 3개)
	- 2-3) 프로필 이미지 — 현재 아바타. 누르면 선택 시트
3. **알림**
	- 3-1) 「알림 받기」 스위치 하나
4. **오늘 이런 알림을 받아요** — 미리보기
	- 4-1) 찜·단골·제보·시세에서 실제로 계산해 한 줄로 조립. 예: "오늘 삼성동 — 감자 12% 내렸어요 · 행복청과에 새 제보 3건"
	- 4-2) 대상이 없으면 "아직 알림 받을 야채나 가게가 없어요. 찜하거나 단골로 등록해 보세요"
	- 4-3) 토글이 꺼져 있으면 흐리게
5. **정보** — 이용약관 / 개인정보 처리방침 / 버전 / 문의하기
6. **로그아웃** — 비회원 상태로 돌아간다. 동네는 유지되고 시세는 계속 볼 수 있다
7. **탈퇴하기** — 확인 시트에 무엇이 지워지고 무엇이 남는지 적는다. 계정·찜·단골·구매 기록은 삭제, 올린 제보는 「탈퇴한 이웃」으로 남는다

#### 알림 트리거

| 대상 | 보낼 때 |
|---|---|
| 찜한 야채 | 최근 평균 대비 일정 비율 이상 내렸을 때만 |
| 단골 가게 | 그 가게에 시세보다 싼 제보가 새로 올라왔을 때만 |

매일의 등락 전부가 아니라 의미 있는 변화만 보낸다.

#### 상태 3종

| 상태 | 처리 |
|---|---|
| 로딩 | 없음 |
| 에러 | 닉네임 변경 시 규칙 위반·중복은 시트 안 인라인 문구 |
| 빈 | 알림 대상 없음 — 미리보기 자리에 안내 문구 |
