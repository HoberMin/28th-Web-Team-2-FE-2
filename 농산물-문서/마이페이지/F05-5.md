# F05-5 마이페이지 · 단골 가게

경로 — `/prototype/mypage/stores`

#### 정책

- 단골 = 구독이다. 별도 등록 없이 알림 대상이 된다. 알림 토글은 여기 없고 F05-1에 있다
- 이 화면은 목록과 해제만 맡는다
- 단골 등록·해제 지점은 셋이다. 가게 상세(F09) 우측 상단, 가게 목록(F07)의 줄, 그리고 여기

#### Description

1. 앱바 — "단골 가게"
2. **목록** — 줄마다 가게명 + 해제 버튼
	- 2-1) 가게명을 누르면 F09
	- 2-2) 해제 버튼은 아이콘 단독이라 이름표로 "{가게명} 단골 해제"를 전달한다
