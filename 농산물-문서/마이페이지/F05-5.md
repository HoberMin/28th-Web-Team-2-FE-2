# F05-5 마이페이지 · 찜한 가게

경로 — `/prototype/mypage/stores`

> 목록과 해제만 맡는 화면. 「단골 가게」라는 말은 코드에서 「찜한 가게」로 바뀌었다.

> **찜 탭(F11) 「가게」 세그먼트와 같은 본문 컴포넌트를 쓴다 — 두 경로가 완전히 같은 기능이다.** 한쪽을 고치면 다른 쪽도 같이 바뀌고, 반대로 진입점만 둘인 중복이라 정리 대상 후보다.
> 가게별 알림 토글은 여기 없다. 전역 토글 하나로 합쳐 F05-1로 옮겼다.

#### 정책

- 찜 = 구독이다. 별도 등록 없이 알림 대상이 된다. 알림 토글은 여기 없고 F05-1에 있다
- 이 화면은 목록과 해제만 맡는다
- 찜 등록·해제 지점은 셋이다. 가게 상세(F09) 앱바 우측 하트, 동네 가게(F07) 지도의 가게 시트 하트, 그리고 여기의 해제 버튼
- 담아두는 행동은 야채든 가게든 하트 하나로 통일한다. 같은 행동에 기호가 둘이면 다른 기능으로 읽힌다

#### Description

1. 앱바 — "찜한 가게". 뒤로가기는 마이페이지
2. **목록** — 최근에 찜한 순
	- 2-1) 줄마다 가게명 + 해제 버튼
	- 2-2) 가게명을 누르면 F09
	- 2-3) 해제 버튼은 아이콘 단독이라 이름표로 "{가게명} 찜 해제"를 전달한다
