# F05-3 마이페이지 · 내 제보

경로 — `/prototype/mypage/reports`

> 오타 제보를 되돌릴 수 있는 유일한 자리. 시스템은 이상치를 흐리게 표시만 하고 본인은 못 고치는 구멍을 막는다.

#### 정책

- 스와이프 삭제를 쓰지 않는다. 있는 줄 모르면 영원히 못 찾고 타깃 연령대에 특히 불리하다. 명시적 메뉴로 노출한다
- 수정은 제보 폼 전체로 되돌리지 않고 가격·양만 고치는 가벼운 시트로 처리한다. 품목·가게는 바꾸지 않는다
- 삭제는 확인 단계를 둔다
- 수정은 덮어쓰기다. 이력을 남기지 않는다. 수정은 대부분 오타 정정이라 틀린 값을 보존할 이유가 없다
- 눌러도 안 되는 버튼은 보여주지 않는다. 수정할 수 없는 항목은 메뉴 자체를 숨긴다

#### Description

1. 앱바 — "내 제보"
2. **목록** — 최신순
	- 2-1) 품목명. 구매하지 않은 제보에는 「시세만 봄」 배지
	- 2-2) 제보일 · 동네
	- 2-3) 우측에 기준 단위 환산가 + 시세 대비 절약·초과. 오늘 시세가 없는 품목(비수기 등)은 비교하지 않는다
	- 2-4) 우측 끝 `⋯` 메뉴
3. **`⋯` 메뉴 시트** — 수정 / 삭제
4. **수정 시트** — 가격·양만. 저장하면 목록에 바로 반영
5. **삭제 확인 시트** — 되돌릴 수 없다는 안내 + 삭제

#### 상태 3종

| 상태 | 처리 |
|---|---|
| 로딩 | 없음 |
| 에러 | 수정 시 가격·양이 0 이하면 저장 비활성 |
| 빈 | "아직 제보한 내역이 없어요. 야채 시세 화면에서 실제 가격을 제보해 보세요" |
