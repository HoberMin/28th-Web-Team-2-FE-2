# F05-4 마이페이지 · 구매

경로 — `/prototype/mypage/purchases`

> 라벨이 「구매 내역」이 아니라 「구매」인 이유는 과거 기록과 다음 구매 안내를 같이 담기 때문이다.

#### 정책

- 구매 목록은 제보할 때 「샀어요」를 고른 것만이다
- 재구매 안내를 홈이 아니라 여기 둔다. 구매 이력이 2건 이상이라야 의미 있는 추정인데, 그쯤이면 마이페이지를 아는 사용자고 데이터 출처도 구매 내역과 같다
- 이력이 1건뿐이면 근거가 없어 기본값(14일)을 쓴다. 가정이라는 걸 문구로 밝힌다
- 절약·초과 계산 기준은 홈·시세 화면과 같은 오늘 시세를 쓴다

#### Description

1. 앱바 — "구매"
2. **살 때 된 야채** — 주기가 지난 품목만, 경과일 순으로 최대 4개
	- 2-1) 우측 상단 근거 라벨 "내 구매 간격 기준"
	- 2-2) 줄마다 썸네일 / 품목명 / "마지막 구매 N일 전 · 보통 N일마다 사셨어요" / 「시세 보기」
	- 2-3) 해당 품목이 없으면 섹션 전체를 그리지 않는다
3. **구매 내역** — 최신순
	- 3-1) 품목명 · 수량 / 구매일 · 동네
	- 3-2) 우측에 지불 금액 + "시세보다 N원 절약" / "시세보다 N원 높음". 절약은 초록, 초과는 주황

절약 총합은 여기서 다시 말하지 않는다. 마이페이지 허브(F05)의 절약 카드가 담당한다.
