# F05 마이페이지 [GNB]

경로 — `/prototype/mypage`

> 허브형. 값으로 봐야 하는 것만 남기고 목록으로 훑는 것은 메뉴 뒤로 보낸다.

#### 정책

- 절약 카드는 메뉴 뒤로 숨기지 않는다. 눈으로 보는 변화가 핵심 가치라, 감추면 마이페이지에 들어올 이유가 사라진다
- 누적과 주간을 카드 두 장으로 나누지 않는다. 같은 지표를 기간만 바꿔 두 번 말하며 화면만 늘린다
- 절약 계산의 기준 시세는 홈·시세 화면과 같은 값을 쓴다. 화면마다 기준이 어긋나면 안 된다
- 제보와 구매를 구분한다. 제보는 내가 올린 전부, 구매는 실제로 산 것만
- 설정 진입점은 리스트 메뉴 맨 아래 「내 정보」 하나. 우측 상단 톱니를 따로 두지 않는다
- 미획득 뱃지도 흐리게 보여준다. 다음 목표가 보여야 유인이 된다

#### Description

1. 앱바 — "마이페이지"
2. **프로필** — 아바타 / 닉네임 / 현재 동네. 닉네임이 없으면 "{동네} 이웃"
3. **절약 카드** — 기간 토글(이번 주 / 전체)
	- 3-1) "{금액}원 아꼈어요". 시세보다 비싸게 샀으면 "시세보다 {금액}원 높았어요". 비난으로 읽히지 않게 사실만 적는다
	- 3-2) 절약은 초록, 초과는 주황
	- 3-3) 가장 잘 산 품목 — "가장 잘 산 건 {품목} — 시세보다 {금액}원 저렴하게 사셨어요 ({가게명})". 칭찬 대상이 구체적이어야 다음 행동으로 이어진다
	- 3-4) 하단에 구매 건수 · 총 지출
	- 3-5) 구매 0건이면 "야채를 사고 가격을 제보하면 시세보다 얼마나 아꼈는지 알려드려요"
	- 3-6) 이번 주 구매만 없으면 "최근 7일엔 구매 기록이 없어요"
4. **뱃지** — 가로 스크롤. 획득 개수 "N/M". 미획득은 흐리게
5. **리스트 메뉴** — 줄마다 개수를 함께 보여준다
	- 5-1) 찜한 야채 · N개 → F05-2
	- 5-2) 내 제보 · N건 → F05-3
	- 5-3) 구매 · N건 → F05-4
	- 5-4) 단골 가게 · N곳(없으면 "없음") → F05-5
	- 5-5) 내 정보 · 닉네임(없으면 "미설정") → F05-1

메뉴 라벨은 「구매 내역」이 아니라 「구매」다. 과거 기록과 다음 구매 안내를 같이 담는다.

#### 상태 3종

| 상태 | 처리 |
