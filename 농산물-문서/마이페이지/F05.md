# F05 마이페이지 [GNB]

경로 — `/prototype/mypage`

> 허브형. 값으로 봐야 하는 것만 남기고 목록으로 훑는 것은 메뉴 뒤로 보낸다.

> 금액 지표(누적·주간 절약액, 총 지출, 구매 건수, "가장 잘 산 건 …")와 뱃지는 화면에서 걷어냈다 — 구매 인증 개념을 버리면서 근거를 잃었다.
> 찜한 야채 목록은 GNB 「찜」 탭(F11)으로 올라갔고, 「내 정보」는 리스트 줄이 아니라 상단 프로필을 눌러 들어간다.
> 로그인 요구 게이트가 없어 비회원도 그대로 들어온다.

#### 정책

- 성과를 금액으로 말하지 않는다. 남는 동기 장치는 주간 캘린더 하나다. "이번 주에 내가 몇 번 알려줬나"를 금액이 아니라 흔적으로 보여준다
- 같은 진입점을 두 번 두지 않는다. 설정은 상단 프로필 한 곳이고, 우측 상단 톱니도 리스트의 「내 정보」 줄도 없다
- 되돌아오는 경로가 잦은 목록은 마이페이지 2단 깊이에 두지 않는다. 찜은 GNB 탭으로 올리고, 여기엔 자주 열지 않는 관리성 목록만 남긴다
- 캘린더 기준일은 서버가 내려준다. 기기 시계로 흔들리면 주가 어긋난다
- 리스트 메뉴는 줄마다 개수를 함께 보여준다. 열어보지 않아도 쌓였는지 알 수 있다

#### Description

1. 앱바 — "마이페이지". GNB 탭 루트라 뒤로가기 없음
2. **프로필** — 줄 전체가 「내 정보」 링크다. 링크라 키보드 포커스·엔터가 그냥 따라온다
	- 2-1) 아바타 — 고른 야채 일러스트. 안 고르면 기본 아이콘
	- 2-2) 이름 — 닉네임. 없으면 "{동네} 이웃", 위치를 아직 모르면 "우리 동네 이웃"
	- 2-3) 아래 줄에 현재 동네. 확인 중이면 "위치 확인 중…"
3. **이번 주 제보** — 월~일 7칸 캘린더
	- 3-1) 제목 "이번 주 제보". 우측에 "{N}일 제보", 없으면 "아직 없어요"
	- 3-2) 제보한 날은 날짜 숫자 대신 그날 제보한 야채 일러스트를 도장으로 찍는다. 같은 날 여러 건이어도 칸은 하나고 첫 제보의 야채를 쓴다
	- 3-3) 제보 없는 날은 날짜 숫자. 오늘 칸은 테두리로 구분한다
	- 3-4) 한 번도 없으면 아래에 "가격을 제보한 날에는 야채 도장이 찍혀요."
4. **리스트 메뉴** — 두 줄뿐이다
	- 4-1) 내 제보 · "{N}건" → F05-3
	- 4-2) 찜한 가게 · "{N}곳"(없으면 "없음") → F05-5

#### 상태 3종

| 상태 | 처리 |
|---|---|
| 로딩 | 동네 자리에 "위치 확인 중…", 이름은 "우리 동네 이웃"으로 폴백 |
| 에러 | 해당 없음 — 서버에서 받는 값은 기준일뿐이다 |
| 빈 | 캘린더는 도장 0개 + 안내 문구. 메뉴는 "0건" / "없음"으로 그대로 노출 |

#### 화면 전환

- 진입 — GNB 「마이페이지」. 로그인 요구 없음
- 프로필 → F05-1
- 「내 제보」 → F05-3
- 「찜한 가게」 → F05-5
- 찜한 야채는 여기 없다 — GNB 「찜」 탭(F11)
