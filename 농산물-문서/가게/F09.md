# F09 가게 상세

경로 — `/prototype/store/{가게명}`

> "이 가게는 뭐가 싸고 뭐가 비싼가"에 한 화면으로 답한다.

#### 정책

- 위치를 가격 목록보다 먼저 둔다. 갈 만한 거리인지가 정해져야 가격을 볼 이유가 생긴다
- 제보가 하나도 없는 가게여도 위치는 보여준다. 그 화면에서 유일하게 확실한 정보다
- 같은 품목은 최신 1건을 대표로 쓴다. 가격은 시간에 민감하다
- 정렬은 시세 대비 싼 품목 순. 방문할 이유가 먼저 읽혀야 한다. 이상치는 정렬과 무관하게 맨 아래
- 섹션 이름은 「이 가게에 제보된 가격」이다. 가게가 게시한 공식 가격표가 아니라 이웃이 보고 남긴 값이라, 이름이 출처를 숨기면 틀린 값의 책임이 가게로 간다
- 댓글은 지금 내 동네에 있는 가게에만 쓸 수 있다
- 뒤로가기는 온 길로 돌아간다. 여러 경로에서 들어오는 화면이라 목적지를 고정하면 오작동한다

#### Description

1. 앱바 — 가게명. 우측에 단골 등록 버튼
	- 1-1) 단골을 켜고 끄면 스크린리더에 "{가게명} 단골로 등록했어요 / 해제했어요"를 알린다. 아이콘 변화만으로는 아무것도 안 읽힌다
2. **요약 한 줄** — 제보 품목 수 / 시세보다 싼 품목 수 / 가장 최근 제보 시점
	- 2-1) 최근 제보는 목록 첫 줄이 아니라 실제 제보 시점이 가장 이른 것을 찾는다. 목록은 싼 순으로 정렬돼 있다
3. **위치** — 지도 / 주소 / 내 위치에서 걸어서 N분
	- 3-1) 지도 앱키가 없으면 지도만 빼고 주소·거리는 남긴다. 화면이 깨지지 않는다
4. **이 가게에 제보된 가격** — 시세 대비 싼 품목 순
	- 4-1) 줄마다 썸네일 / 품목명 / 가격 / 시세 대비 차이
	- 4-2) 최신도 · 확인 인원 · 이상치 표시는 F03과 같은 규칙
	- 4-3) 이상치는 맨 아래로
5. **가게 신선도 후기** — 좋아요 / 보통 / 별로 개수와 한마디. F04-3에서 받은 값
6. **가게 댓글** — 닉네임 + 내용
	- 6-1) 지금 동네 가게가 아니면 입력 칸을 막는다
	- 6-2) 한글 입력 중 엔터로 미완성 글자가 제출되지 않게

#### 없는 가게로 들어온 경우

URL을 직접 조작해 들어올 수 있다. 아는 가게 목록·단골·내 제보 어디에도 없는 이름이면 "찾을 수 없는 가게예요 / 주소가 바뀌었거나 없는 가게일 수 있어요" + 「가게 둘러보기」(F07).

#### 상태 3종

| 상태 | 처리 |
|---|---|
| 로딩 | 제보·댓글을 불러오기 전에는 자리표시 3줄. 그대로 그리면 "제보 없음"이 한 번 깜빡였다 목록으로 바뀐다 |
| 에러 | 없는 가게 — 위 「없는 가게로 들어온 경우」 |
| 빈 | 제보 0건이어도 위치는 남긴다. 댓글 0건이면 빈 상태 문구 |
