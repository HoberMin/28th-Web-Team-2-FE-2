# F07 동네 가게 [GNB]

경로 — `/prototype/stores`

> "오늘 어디로 갈까"에 정면으로 답하는 화면. 나머지 화면은 전부 품목 축이다.

> 화면 전체가 지도다. 앱바도 스크롤도 없고, 순위 목록·「내 단골 가게」 섹션은 없다(2026-08-04 개편으로 목록 두 층을 걷어냈다).
> 지도는 실제 SDK가 아니라 회색 배경 + 「지도」 라벨이고, 핀 위치는 동 중심 대비 가게명 해시 오프셋을 %로 편 값이다 — 지리 정확도가 없다.
> 「단골」은 「찜」으로 용어가 통일됐다. 이 화면의 찜 토글·FAB·저장 키(`veg-favorite-stores-v1`)가 모두 찜이다.

#### 정책

- 지도를 실제 지도 SDK로 그리지 않는다. 앱키 설정·도메인 등록에 기대면 로컬·배포 프리뷰마다 렌더 여부가 갈린다. 이 화면이 검증하려는 건 "핀을 눌러 가게를 본다"는 인터랙션이라 가짜 배경 위 상대 위치로 충분하다. 가게 상세(F09)의 지도는 반대로 실제 Kakao SDK를 쓴다 — 한 서비스 안에 지도 실현도가 두 종류인 상태다
- 핀 좌표는 실좌표 투영이 아니다. 「서로 겹치지 않게 흩어져 있다」는 느낌만 만든다. 시트의 거리·도보 시간도 이 가짜 좌표에서 나온 값이라 실측이 아니다
- 비교 기준이 되는 시세는 서버에서 내려주고 가게 집계는 클라(localStorage 제보)에서 만든다. 클라에서 기준까지 만들면 화면마다 숫자가 갈린다
- 가게 평균은 제보가 평균이 아니라 시세 대비 편차 평균이다. 금액을 그대로 평균 내면 비싼 품목이 많이 제보된 가게가 무조건 비싸 보이고, 가게가 아니라 품목 구성을 비교하게 된다
- 평균 계산에서 이상치(시세의 3배↑ · ⅓↓)와 낡은 제보(7일 초과)를 같은 잣대로 뺀다. 낡은 제보를 경고하면서 집계엔 같은 무게로 반영하면 경고와 숫자가 서로 반박한다
- 가게를 안 고른 제보는 집계에 안 들어간다. 시세 집계에는 쓰인다
- FAB의 기본값은 「전체」다. 처음 온 사람에게 찜은 0개라 켜진 상태로 시작하면 빈 지도를 준다
- 순위 번호는 매기지 않는다. 지도에는 줄 세울 자리가 없고, 집계 정렬(싼 순 → 제보 많은 순)은 핀 렌더 순서에만 남아 화면에 보이지 않는다 *(순위 표기는 폐기된 개념이 아니라 이 화면에서 표현 수단이 없어 빠진 상태다)*

#### Description

1. 지도 — 화면을 꽉 채운다. 앱바·스크롤 없이 지도가 프레임 전체이고, 중앙에 「지도」 라벨(낭독 제외)
2. **가게 핀** — 가게명이 적힌 알약 버튼
	- 2-1) 찜한 가게는 이름 앞에 `♥`가 붙는다
	- 2-2) 아이콘·이름만으로는 무엇을 하는 버튼인지 안 읽히므로 "{가게명} 정보 보기"로 낭독한다
	- 2-3) 누르면 바텀시트가 열린다. 화면을 통째로 덮지 않아 지도 맥락이 유지된다
3. **FAB(우측 하단 하트)** — 찜한 가게만 지도에 남긴다
	- 3-1) 꺼짐은 빈 하트, 켜짐은 채운 하트 + 강조 배경. 색 하나에 의존하지 않고 `aria-pressed`로도 상태를 알린다
	- 3-2) 낭독 문구는 꺼짐 "찜한 가게만 보기" / 켜짐 "찜한 가게만 보기 해제"
	- 3-3) 켠 상태에서 찜이 0개면 핀 대신 빈 상태 문구가 뜬다
4. **바텀시트** — 제목은 가게명, 핸들 있음. 「지금 갈까」를 정하는 최소값만 담고 전체 품목·댓글은 상세로 넘긴다
	- 4-1) "내 위치에서 {거리} · 걸어서 {N}분"
	- 4-2) "시세보다 평균 N% 저렴" 또는 "시세보다 평균 N% 비쌈". 비교할 제보가 부족하면 "아직 시세와 비교할 제보가 부족해요"
	- 4-3) "저렴한 야채 N가지 · 제보된 품목 N개 · {오늘/어제/N일 전} 제보"
	- 4-4) **최근 제보** — 최대 3건. 썸네일 / 품목명 / 가격 / 제보 시점 태그. 시트는 싼 순이 아니라 제보 시점 최신순이고, 이상치는 뺀다. 압축 미리보기라 「확인 필요」 경고를 붙일 자리가 없어 그대로 두면 오타성 가격이 정상처럼 읽힌다
	- 4-5) 「가게 상세 보기」(F09) + 우측 찜 토글. 찜은 시트에서 바로 끝난다 — 지도를 보다 "여기 담아둘래"에 화면 이동이 끼면 안 된다

#### 상태 3종

| 상태 | 처리 |
|---|---|
| 로딩 | 위치를 못 불러온 동안은 집계하지 않는다. 자리표시 없이 핀이 0개인 상태여서, 빈 상태 문구가 잠깐 스친 뒤 핀이 채워진다 *(스켈레톤 미구현)* |
| 에러 | 시세 조회 실패 시 더미 기준선으로 폴백한다. 화면에 별도 에러 표기는 없다 |
| 빈 | 전체 보기 — "아직 {동네}에 가게별 제보가 없어요. / 제보할 때 가게를 골라주시면 여기 핀이 생겨요." · 찜만 보기 — "찜한 가게가 아직 없어요. / 가게 상세에서 하트를 눌러 담아보세요." |

#### 화면 전환

- 진입 — GNB 「동네 가게」, F09의 「가게 둘러보기」
- 핀 → 바텀시트 → 「가게 상세 보기」 → F09
