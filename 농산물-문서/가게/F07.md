# F07 동네 가게 [GNB]

경로 — `/prototype/stores`

> "오늘 어디로 갈까"에 정면으로 답하는 화면. 나머지 화면은 전부 품목 축이다.

#### 정책

- 순위 기준은 제보가 평균이 아니라 시세 대비 편차 평균이다. 가게마다 제보된 품목 구성이 달라서, 금액을 그대로 평균 내면 비싼 품목이 많이 제보된 가게가 무조건 비싸 보이고 가게가 아니라 품목 구성을 비교하게 된다
- 동점이면 제보가 많은 쪽이 위. 근거가 두꺼운 쪽을 먼저 보여준다
- 순위는 전체 기준으로 먼저 매기고 나서 단골·나머지로 나눈다. 단골을 뺀 뒤 다시 1번부터 매기면 실제 1위를 단골로 등록한 순간 2위가 1위로 보인다
- 단골이 0개여도 하단 목록이 화면을 채운다. 첫 사용자에게 빈 탭을 주지 않는다
- 순위는 제보가 올라오는 즉시 다시 계산한다
- 가게를 안 고른 제보(「가게 없이 제보하기」)는 이 목록에 안 들어간다. 시세 집계에는 쓰인다

#### Description

1. 앱바 — "가게"
2. **내 단골 가게** — 단골이 있을 때만. 전체 순위 번호를 그대로 달고 나온다
	- 2-1) 다른 동네 단골이 있으면 "다른 동네 단골 N곳은 지금 동네 목록에 안 보여요". 데이터는 남아 있는데 목록에서만 빠진 것이라 사라졌다고 오해하지 않게 한다
3. **{동네} 가게** — 시세 대비 싼 순
	- 3-1) 부제 "오늘 시세 대비 · 이웃 제보 기준 싼 가게 순"
4. **가게 줄** (양쪽 공통)
	- 4-1) 순위 / 가게명 / 걸어서 N분 / 최신도 태그
	- 4-2) 우측에 시세 대비 평균 %. 가게명과 같거나 더 크게. 이 목록의 정렬 기준값이다
	- 4-3) 그 아래 근거 두께 — 교차검증된 품목 수, 없으면 제보 건수. 1건짜리 가게가 20건짜리와 같은 무게로 보이면 안 된다
	- 4-4) 우측 끝 단골 토글. 아이콘만 있는 버튼이라 켜짐·꺼짐을 이름표로도 전달한다
	- 4-5) 줄을 누르면 F09

거리는 도보 시간 하나로만 적는다. 거리와 도보 시간은 같은 사실의 두 표현이고, 좌표가 가게명 해시로 만든 값이라 정밀도도 없다.

| 상태 | 처리 |
