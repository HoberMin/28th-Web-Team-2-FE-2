### 자산 7건은 원인이 하나다

SVG가 프레임(48×48 / 24×24)이 아니라 **그림만 트림돼서** export돼 있다. 같은 슬롯에 넣으면 각자 자기 viewBox를 꽉 채우려 확대돼 크기가 제각각으로 보인다.

```
onion.svg        viewBox 0 0 30 33.02      ← 트림됨
carrot.svg       viewBox 0 0 31 39.63      ← 트림됨
garlic.svg       viewBox 0 0 48 48         ← 프레임째 (정상)
person-fill.svg  viewBox 0 0 19.5 20.15    ← 트림됨
home.svg         viewBox 0 0 24 24         ← 프레임째 (정상)
```

**→ 프레임째 다시 받으면 코드 수정 없이 7건이 한 번에 해결된다.**

## ⚠️ 확인이 필요한 판단 2건

QA 문구를 그대로 따르면 다른 규칙과 충돌해서 절충한 지점이다. 의도와 다르면 알려주세요.

**45번 — 파란 스트로크 "아예 안 뜨게"**
포커스 표시를 완전히 없애면 WCAG 2.4.7 위반이라 키보드 사용자가 커서 위치를 잃는다. 브라우저 기본 파란 링만 걷어내고, **Figma가 `field/price` "상태: 입력중"에 실제로 쓰는 `border/tertiary`(#4a5667)** 로 대체했다(임의 색 아님).

**28번 — 스크롤 전 헤더 숨김**
헤더 전체를 숨기면 초기 화면에서 라우트를 벗어날 수단이 사라진다(PWA·인앱 브라우저엔 뒤로가기가 없는 경우가 있다). 배경·구분선·제목만 숨기고 **뒤로가기 버튼은 항상 남겼다.**
