# F06 랭킹 [GNB]

경로 — `/prototype/ranking`

> 제보왕 단독 화면. 싼 가게는 F07로, 최저가 품목은 홈으로 옮겼다.

#### 정책

- 공개하는 값은 닉네임·아바타·순위·제보 건수까지. 본명은 쓰지 않는다
- 현재 동네 기준으로만 집계한다. 제보하면 그 자리에서 순위가 오른다. 하루 1회 배치로 미루지 않는다
- 비교값은 닉네임이 아니라 제보 건수다. 건수를 더 크게

#### Description

1. 앱바 — "랭킹"
2. 제목 "이번 주 랭킹" + 부제 "{동네} 기준 · 제보 건수 순"
3. **TOP3 포디움** — 2-1-3 계단 배치. 1위가 가운데이자 제일 높고 브랜드색
	- 3-1) 제보왕이 1~2명뿐일 수 있다. 있는 만큼만 그리고, 2위가 없어도 1위 자리가 어긋나지 않는다
4. **4위부터 리스트** — 순위 / 아바타 / 닉네임 / 제보 건수
5. 포디움·리스트 어느 쪽을 눌러도 같은 목적지(F06-1)
