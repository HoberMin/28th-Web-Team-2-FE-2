# F06-1 공개 제보 목록

경로 — `/prototype/reporter/{닉네임}`

#### 정책

- 공개하는 값은 닉네임·아바타·순위·건수와 제보 목록(품목·가격·가게·시점)까지. 구매 여부와 절약액은 개인 정보라 넣지 않는다. 그건 마이페이지 「내 제보」만의 값이다
- 순위는 제보왕 화면과 같은 범위(현재 동네)로 계산한다. 다른 기준을 쓰면 방금 본 순위와 어긋난다

#### Description

1. 앱바 — 닉네임. 뒤로가기는 온 길, 없으면 F06
2. **프로필** — 아바타 / 닉네임 / "{동네} N위 · 제보 N건"
3. **제보 목록** — 최신순
	- 3-1) 줄마다 썸네일 / 품목명 / 가게명 / 가격 / 제보 시점
	- 3-2) 가게를 안 고른 제보는 "{동네} · 가게 미상"

#### 상태 3종

| 상태 | 처리 |
|---|---|
| 로딩 | 위치를 못 불러온 동안 자리표시. 앱바 제목은 "제보왕" |
| 에러 | 목록에 없는 닉네임 — "이 이웃을 찾을 수 없어요 / {동네} 제보왕 목록에 없는 닉네임이에요" |
| 빈 | "아직 공개할 제보가 없어요" |
