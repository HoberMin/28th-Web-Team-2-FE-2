## 이번에 알게 된 것

8월 20일 수정 중 세 건(29 · 35 · 19)이 **코드에는 들어갔는데 화면에는 안 나타나고 있었다.** 공통 원인은 `cn()`이 tailwind-merge가 아니라 단순 이어붙이기라, 같은 CSS 속성의 유틸이 한 요소에 둘 붙으면 승자가 클래스 순서가 아니라 생성된 CSS 순서로 정해진다는 점이다.

이번에 `TextField.placeholderTone` · `Button.radius` · `ButtonCircle.surface/elevated/inheritColor` 축을 뚫어, 덮어쓰기 대신 prop으로 푸는 경로를 만들었다. 전 파일을 기계적으로 스캔해 같은 유형이 더 없는지도 확인했다.
