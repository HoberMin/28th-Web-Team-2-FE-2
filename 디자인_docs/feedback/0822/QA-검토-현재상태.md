## 현재 코드에서 추가로 확인된 변경

- 야채 선택 2단 화면의 `제보할 야채를 선택해주세요` 안내 문구를 제거했다. 검색 필드가 바로 시작하도록 레이아웃도 함께 정리했다.
- 제보 단위는 `FieldUnitDisplay`에서 선택형으로 복원했다. 선택값은 `unit` payload로 제출되고, 판매 장소 화면을 다녀와도 `unit` 쿼리로 유지된다.
- 전달된 아이콘은 `public/figma/design-library/icons/`에 반영했고, `information-circle-2`와 `person-fill` 적용까지 완료했다.
- 홈 최저가 야채 목록을 `ROUTES.priceDetail(itemId)` 링크로 연결했다.
- 가게 상세 sheet가 열릴 때 탭 GNB를 숨기고, sheet가 닫히면 복원하도록 공용 탭 chrome 상태를 추가했다.
- `tab/bar(wide)` 선택 인디케이터가 선택 탭으로 이동하도록 전환을 추가했다.
- 가게 상세와 야채 상세의 제보 CTA가 기존 매장 ID와 품목 ID를 각각 전달해 제보 폼에 자동 선택되도록 연결했다.
- 최신 야채 상세 기준으로 별도 `어제 대비` 라벨을 제거하고 등락값을 `오늘 공공 시세` 바로 아래에 배치했다.
