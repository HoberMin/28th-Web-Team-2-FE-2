# 디자인시스템 리뷰 — 컴포넌트

[component 섹션](https://www.figma.com/design/WfW1Nkx1oiOWBHNwrw48IL/Design-Library?node-id=437-28228) 실측 · 2026-08-19
대상 이름을 누르면 피그마로 이동합니다. 위쪽일수록 손이 미끄러진 것에 가깝고, 아래로 갈수록 판단이 필요한 항목입니다.
대비·색감처럼 보고 정하신 부분은 다루지 않았습니다. 토큰 연결 문제는 같은 폴더의 토큰 문서로 뺐고, 오타·더미 문구와 렌더 결과가 같은 이름 취향도 뺐습니다.
