## 이미 코드가 피그마에 맞춘 것

- text/vegetable-trend에 방향 축(down·up·flat)을 넣었습니다. 기존 코드는 down 고정에 색이 직접 입력돼 있었습니다
- button/circle에 크기 축(36·48)을 넣고 36px 그림자 blur 2.25px용 토큰을 따로 만들었습니다
- button/base의 secondary 눌림을 크기별로 갈랐습니다. Figma가 medium과 small에 다른 토큰을 물려 놨기 때문입니다
- 정렬 시트 계열 네 규격(sheet/sort · list/sort-option · row/sort-option · sheet/handle)을 Design Library를 정본으로 삼아 구현했습니다
- badge/reporter-rank 네 등급 글자 색을 v03 content/rank 토큰으로 교체했습니다 (위 6번)

## 아직 못 맞춘 것

- card/recommended-store 배경 그라데이션 — 원본이 어느 Variable에도 안 묶여 있고 우리 팔레트에도 없습니다. 추측 매핑도 색값 직접 입력도 금지라 배경을 비워 뒀습니다. Variable로 등록하거나 기존 토큰 대체를 승인해 주셔야 닫힙니다
- 새로 생긴 규격 약 40개 — 위 1~6번이 풀려야 시작할 수 있습니다
- 제보 화면 부품 8개(app/report) — 구현은 돼 있는데 어느 화면에도 연결되지 않았고 playground 스토리도 없습니다. 지금은 배포본에서 확인할 방법이 없어, 위 40개에 이 8개가 섞여 있을 수 있습니다. 스토리를 붙이고 다시 세겠습니다
