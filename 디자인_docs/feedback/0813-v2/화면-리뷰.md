대상 이름을 누르면 피그마로 이동합니다. 위쪽일수록 오류에 가깝고, 아래로 갈수록 판단이 필요한 항목입니다.

같은 날짜의 [디자인시스템-리뷰.md](./디자인시스템-리뷰.md)는 Variables v03 토큰편, [컴포넌트-리뷰.md](./컴포넌트-리뷰.md)는 컴포넌트편입니다. 이 문서는 화면편이고 번호는 각각 1부터 셉니다.

실측 범위를 밝힙니다. 48프레임 전부 레이어 구조와 좌표·크기를 읽었고, 그중 4프레임([온보딩 인트로](https://www.figma.com/design/d5j7K9BNpSXxVUu3fmZfY4/%EC%9E%A5%EB%B3%B4%EA%B3%A0-Design?node-id=364-7926) · [닉네임 에러](https://www.figma.com/design/d5j7K9BNpSXxVUu3fmZfY4/%EC%9E%A5%EB%B3%B4%EA%B3%A0-Design?node-id=364-7986) · [지역 선택](https://www.figma.com/design/d5j7K9BNpSXxVUu3fmZfY4/%EC%9E%A5%EB%B3%B4%EA%B3%A0-Design?node-id=364-8011) · [홈 추천 카드](https://www.figma.com/design/d5j7K9BNpSXxVUu3fmZfY4/%EC%9E%A5%EB%B3%B4%EA%B3%A0-Design?node-id=364-6807))과 제보 흐름 12프레임은 토큰 바인딩·타이포까지 봤습니다. 야채시세 상세의 목록·차트·댓글 세 구획은 내부 px을 재지 않았습니다. 아래 아직 못 맞춘 것에 적었습니다.

## 이미 코드가 피그마에 맞춘 것

- 제보 흐름 12프레임을 전부 구현했습니다. 라우트는 /report · /report/vegetable · /report/place · /report/done입니다
- 홈 헤더 좌우 여백이 8과 8로 대칭이 됐습니다. 구 14번이 해소됐습니다
- 시세상세 요약에 온라인 최저가 행을 추가했습니다. [364:7185](https://www.figma.com/design/d5j7K9BNpSXxVUu3fmZfY4/%EC%9E%A5%EB%B3%B4%EA%B3%A0-Design?node-id=364-7185)가 시안에 있는데 코드에 빠져 있었습니다
- 가게상세 프로필의 아이콘 20에서 22, chevron 16에서 12, 주소·영업시간 글자 12px에서 14px로 맞췄습니다. 영업 상태 사이 중간점도 2x2 dot 요소로 바꿨습니다
- 가게상세 통계 배지의 두 번째 색을 content/brand/light에서 content/brand/dark로 고치고 라벨·숫자 굵기를 medium·bold로 갈랐습니다
- 홈 추천 가게 카드의 image/grass를 30으로 되돌렸습니다. 코드가 근거 없이 1.6배 확대해 두고 있었습니다
- 온보딩 닉네임·지역의 heading에서 입력까지 간격을 28로 맞추고 결과 제목의 구분선을 독립 레이어에서 제목의 위 테두리로 옮겼습니다
- 찜 탭 여백을 17과 20으로 맞췄습니다

## 아직 못 맞춘 것

- 야채시세 상세 9프레임 중 store-list-section · price-chart-section · comment-section은 내부 px을 재지 않았습니다. 3번(body 고정 높이)이 풀리면 이어서 맞추겠습니다
- 가게상세의 사진 있음 + 영업시간 접힘, 사진 없음 + 펼침 두 조합은 프레임이 없어 구현하지 않았습니다(4번)
- TextField의 검색어 지우기 버튼이 24px로 터치 기준 44 미달입니다. 공통 컴포넌트가 trailing 슬롯을 size-6으로 고정해 화면에서 넓힐 수 없습니다. 컴포넌트 규격 변경이라 별도 세션입니다
- 화면 코드 이름이 shared/pages.md와 어긋나 있었습니다. Figma를 정본으로 정하고 pages.md를 F04-1~4로 갱신했습니다. 그 과정에서 F04-3 판매 장소 선택이 2026-07-30에 삭제한 화면임을 확인했습니다. 삭제 근거 중 순서가 반대라는 건은 해소됐지만(폼 다음에 열림) 화면이 하나 늘고 폼을 떠났다 오는 사이 입력값이 날아갈 위험이 생깁니다. 코드는 선택값을 URL 파라미터로 물고 다니게 해서 두 번째만 막았습니다. 되돌린 이유를 알려주시면 나머지도 맞추겠습니다
