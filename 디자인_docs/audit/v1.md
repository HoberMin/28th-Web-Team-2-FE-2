## 사각지대

- **E-4**: `get_libraries`·`search_design_system`을 돌리지 않아 인스턴스가 라이브러리 마스터를 참조하는지 로컬인지 확정 못 함. E-1의 50종은 "라이브러리 실측 기록에 없다"는 정황 근거뿐.
- **C(토큰)**: `get_variable_defs`를 `639:7892` 한 화면에만 돌림. 나머지 46개 화면에 다른 raw 값·미바인딩 레이어가 더 있을 수 있음. 화면당 1회씩 전수로 돌리려면 추가 46회 호출 필요.
- **바인딩 자체가 없는 레이어**: `get_variable_defs`는 바인딩된 변수만 반환하므로 "아예 raw hex로 박힌 레이어"는 이 방법으로 안 잡힘. `get_design_context`를 노드별로 돌려야 확인되는데 노드당 ~3k 토큰이라 1,593개엔 비현실적 — 의심 구간을 좁히면 그 부분만 추가 조사 가능.
- **z-order**: 겹침 판정을 형제 노드 bounding box로만 함. 회전·클리핑(`clipsContent`)·블렌드 모드는 메타데이터에 없어 반영 못 함.
- **4px/2px 이탈 940건** 중 콘텐츠 종속값(텍스트 hug 폭 등)과 진짜 레이아웃 이탈을 자동으로 못 갈랐음. D-55~63은 수동으로 고른 것이고 놓친 게 더 있을 수 있음.
